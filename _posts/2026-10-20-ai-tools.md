## 말 끝나기 전에 움직이는 음성 에이전트, 도구를 넘나드는 공유 메모리

오늘 도구 소식은 '맥락을 끊지 않는 것'으로 묶입니다. 음성 대화 도중에 판단을 내리는 API, 여러 AI 도구가 같은 기억을 쓰는 메모리 시스템, 번역 앱을 여행 가이드로 바꾼 국내 서비스가 나왔습니다.

### 오픈AI, 'GPT-라이브'가 '디시전스' API를 직접 호출: 사용자 말이 끝나기 전에 행동 결정

오픈AI가 15일(현지시간) 개발자 업데이트에서 음성 모델 GPT-라이브가 의사결정 API '디시전스'를 직접 부를 수 있게 했습니다(AI타임스 19일 보도). 지금까지는 앱이 두 API 사이를 중계해야 했지만, 이제 음성 모델이 스스로 판단을 요청해 처리 단계가 하나 줄었습니다. 디시전스는 텍스트·이미지를 분석해 정해진 형식으로 답을 돌려주며, 오픈AI는 일반 Responses API보다 약 10배 빠르다고 밝혔습니다. 운전자가 "좀 춥네"라고 말하는 도중 차량 온도를 올리기로 결정하거나, 사용자가 취업 소식을 전하는 순간 가상 캐릭터가 웃게 만드는 식의 활용이 예시로 제시됐습니다. 다만 디시전스는 여전히 베타이며, 잘못 알아들은 말로 동작이 중복 실행되지 않도록 개발자가 허용 동작을 제한해야 합니다. 지난 17일 다룬 GPT-Live-1.1 음성 추가의 후속으로, 이번에는 사용자 기능이 아닌 개발자용 API 변경입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216402)

### 텐센트 '하이 메모리 2.0': 클로드 코드·커서·코덱스가 같은 기억을 공유

텐센트가 16일 여러 챗봇과 코딩 도구가 사용자의 대화·작업 기록을 한 저장소에서 공유하는 오픈소스 메모리 시스템 '하이 메모리 2.0'을 공개했습니다. 전용 모델(Hy-Memory-30B-A3B, 총 약 300억·활성 약 30억 파라미터 MoE), 개발자용 SDK, 데스크톱 앱 '멤허브' 세 층으로 구성되며, 멤허브는 클로드 코드·커서·코덱스·오픈코드 등 10개 이상 도구를 플러그인으로 지원합니다. 커서에서 시작한 프로젝트를 코덱스로 옮겨도 이전 결정과 코드 변경 이력이 이어지는 구조입니다. 텐센트는 LoCoMo 대화 메모리 평가에서 정확도 72.6%를 기록하면서 질문당 토큰을 1159개에서 703개로 39.3% 줄였고, CodeMemoryBench에서 QA 정확도 64.2%를 냈다고 밝혔습니다. 메모리를 특정 서비스가 아닌 사용자 쪽(로컬)에 두는 설계라 도구 간 이동 비용을 낮춘다는 점이 의미가 있습니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216413)

### 네이버 파파고 '트렌드': 외국인 이미지 번역 데이터로 뽑은 인기 상품·장소 톱100

네이버가 19일 번역 앱 파파고에 외국인 방문객용 '트렌드' 서비스를 추가했습니다. 외국인 사용자의 이미지 번역 데이터를 바탕으로 가장 많이 찾는 상품과 장소를 톱100과 '급상승' 목록으로 보여주며, 상품은 뷰티·식품·건강 등 카테고리별, 장소는 명동·홍대·성수·제주·부산 등 지역별로 묶었습니다. 상품에는 'AI 브리핑' 요약과 블로그·네이버쇼핑 후기가 붙고, 장소는 네이버 플레이스와 연동돼 길찾기와 예약까지 이어집니다. 지원 언어는 영어·일본어·중국어 간체·번체 4개입니다. 번역이라는 단일 기능에서 정보 탐색·예약까지 '행동'으로 확장하려는 시도입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216387)

### 마키나락스 '드로우엑스': 흩어진 제조 도면을 AI가 읽는 데이터로

마키나락스가 PC·이메일·공유 폴더에 흩어진 도면을 AI가 읽을 수 있는 데이터로 바꿔 검색·비교·분석하는 솔루션 '드로우엑스'를 내놨습니다(19일 보도). 자연어 도면 검색, 유사 도면 찾기, 버전 간 변경점 자동 탐지, 원자재·공정·리스크를 반영한 AI 원가 리포트, 생산 진행 여부를 판단 근거와 함께 제시하는 기능 등 5가지가 핵심입니다. 회사는 21일부터 3일간 킨텍스에서 열리는 '2026 산업 AI 엑스포'에서 이를 선보입니다. 제조 AX에서 정형 데이터가 아닌 도면이 병목이라는 문제의식을 겨냥한 제품입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216397)
