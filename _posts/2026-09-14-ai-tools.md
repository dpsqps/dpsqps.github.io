## 9월 14일부터 적용되는 두 가지 사용 조건 변경: 코딩 에이전트 한도와 API 라우팅

오늘(14일)은 개발자 도구 두 곳에서 예고됐던 변경이 실제로 적용되는 날입니다. 모델이 새로 나온 건 없지만, 매주 쓸 수 있는 작업량과 API 호출이 어느 모델로 가는지가 달라집니다.

### Claude Code 주간 한도, '25% 인상'이 오늘 적용: 체감은 17% 감소

앤트로픽은 8월 29일 예고한 대로 9월 14일부터 Claude Code의 표준 주간 사용 한도를 프로모션 이전 기준 대비 **25% 영구 인상**합니다. 대상은 Pro·Max·Team 요금제와 좌석 기반 Enterprise이고, 무료 요금제와 사용량 기반 Enterprise는 빠집니다. 다만 5월부터 9월 13일까지는 **50% 임시 증량**이 적용돼 있었습니다. 원래 기준을 100으로 두면 어제까지 150, 오늘부터 125이므로 직전 대비로는 **약 17% 감소**입니다. 앤트로픽도 "지금과 비교하면 주간 한도가 17% 줄어드는 셈"이라고 설명했습니다. 5시간 단위 세션 한도는 그대로 유지됩니다. 임시 증량에 맞춰 워크플로를 짠 헤비 유저는 이번 주부터 한도에 걸릴 가능성이 높고, 한도에 닿은 적이 없는 사용자는 원래 기준(100)보다 여전히 넉넉합니다. [BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-is-cutting-claude-codes-current-weekly-limits-by-17-percent/) / [Digital Applied](https://www.digitalapplied.com/blog/claude-code-weekly-limit-reduction-september-14)

### (후속) 딥시크, 'V4 Pro 전량 Flash 전환'을 철회하고 14일 이후에도 V4 Pro API 유지

딥시크는 V4.1-Flash를 출시하면서 `deepseek-v4-pro` 요청을 14일 04:00(UTC)부터 V4.1-Flash로 돌리겠다고 예고했었습니다. 이후 API 변경 기록에 "사용자 요구에 따라 **2026년 9월 14일 이후에도** DeepSeek V4 Pro API 서비스를 계속 제공하며, 과금 방식은 바뀌지 않는다"는 공지를 추가했습니다. 반면 구세대 `deepseek-v4-flash`와 `deepseek-v4-flash-vision-exp`는 이미 종료됐고, 호환을 위해 V4.1 Flash로 임시 연결됩니다. 같은 기록에서 V4.1-Flash의 GPQA Diamond 점수는 **90.9**로 제시됐습니다. 벤치마크 점수가 더 높은 경량 모델이 나와도 기존 대형 모델의 출력 특성에 맞춘 파이프라인이 있으면 강제 전환은 반발을 부른다는 사례입니다. [DeepSeek API Change Log](https://api-docs.deepseek.com/updates/)
