## 성능은 붙었고 가격표가 갈렸다: 프런티어 모델의 새 승부처

12일 하루에만 신모델 한 종과 대형 오픈웨이트 계획, 그리고 실패한 가성비 도전이 동시에 공개됐다. 세 소식을 관통하는 축은 벤치마크 점수가 아니라 '같은 점수를 얼마에 파느냐'다.

### SpaceXAI 그록 4.6, 최상위권 점수를 3분의 1 가격에

SpaceXAI가 8월 12일 그록 4.6을 공개했다. Artificial Analysis Intelligence Index에서 61점을 기록해 오픈AI의 GPT-5.6 Sol(61점)과 동점을 이뤘고, 선두인 클로드 오퍼스 5(63점)와 클로드 페이블 5(62점)에 2점 이내로 따라붙었다. 에이전트 성능을 보는 GDPval-AA v2에서는 Elo 1,753점으로 2위, 복잡한 워크플로는 약 53단계까지 수행했다. 결정적인 건 가격이다. 100만 토큰당 입력 2달러·출력 6달러로, 오퍼스 5(5/25달러)나 GPT-5.6 Sol(5/30달러)보다 60% 이상 저렴하다. API와 함께 커서·Grok Build·OpenRouter·버셀·클라우드플레어에서 곧바로 쓸 수 있고, 첫 주에는 Grok Build와 커서에서 사용량 쿼터를 두 배로 준다. [The Decoder](https://the-decoder.com/spacexais-grok-4-6-matches-openais-best-model-and-undercuts-it-on-price/)

### 엔비디아 네모트론 4, 1조 파라미터 오픈웨이트를 겨눈다

엔비디아가 최소 1조 파라미터 규모의 네모트론 4 제품군을 준비 중이라고 디 인포메이션이 보도했다. 전작 네모트론 3 울트라의 두 배 규모로, 이르면 올가을 공개될 수 있다는 게 내부 관계자의 전언이다. 다만 엔비디아는 파라미터 수도 시점도 공식 확인하지 않았다. 자체 모델 학습을 위한 클라우드 지출은 2031년까지 280억 달러로 세 배 늘렸다. 흥미로운 대목은 1조라는 숫자가 이미 최전선이 아니라는 점이다. 중국 랩들이 내놓은 키미 K3는 2.8조, 딥시크 V4 프로는 1.6조 파라미터로 이 규모를 넘어섰다. 칩을 파는 회사가 직접 개방형 모델까지 만드는 이유는 명확하다. 추론 비용 압박과 값싼 중국 모델의 부상 속에서 자사 하드웨어를 채울 개방형 수요를 스스로 확보하려는 것이다. [The Decoder](https://the-decoder.com/nvidias-nemotron-4-aims-for-one-trillion-parameters-a-scale-chinese-labs-already-surpassed/)

### 마이크로소프트 MAI Code 1.1 Flash, 가격·성능 모두 딥시크에 밀렸다

마이크로소프트가 코딩용 경량 모델 MAI Code 1.1 Flash를 내놓으며 토큰 효율 25% 개선과 전작 대비 4분의 1 가격을 내세웠지만, 비교표는 냉정했다. SWE-bench Verified는 72.6%를 기록했으나 Terminal Bench 2.1에서는 62.9%로, 딥시크 V4 플래시(0731)의 82.7%에 20%포인트 가까이 뒤졌다. 가격도 딥시크가 입력 0.14달러·출력 0.28달러(캐시 입력 0.0028달러)인 반면 MAI Code 1.1 Flash는 입력 0.20달러·출력 1.20달러로 출력 기준 4배 이상 비싸다. 참고로 클로드 하이쿠 4.5는 입력 1달러·출력 5달러다. 마이크로소프트가 공식 발표에서 경쟁 모델 직접 비교 대신 "코드 생존율 4% 상승" 같은 모호한 지표를 앞세운 것도 이 격차와 무관하지 않다. [The Decoder](https://the-decoder.com/microsofts-new-mai-code-1-1-flash-gets-crushed-by-deepseek-on-both-price-and-performance/)
