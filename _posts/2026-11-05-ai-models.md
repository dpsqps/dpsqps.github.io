## 에이전트 모델, 성능보다 '가격 대비 속도' 경쟁으로

11월 4일 나온 두 모델은 방향이 같습니다. 텐센트는 컴퓨터 사용 기능을 더한 정식 Hy4를 프리뷰와 같은 가격에 내놨고, 코그니션은 플래그십의 5분의 1 가격으로 3배 빠른 코딩 모델을 공개했습니다.

### 텐센트 'Hy4' 정식 출시: 컴퓨터 사용 기능 첫 탑재, 가격은 프리뷰 그대로

텐센트가 11월 4일 대형 언어 모델 Hy4를 공개했습니다. 시각 이해, 추론, 도구 호출을 묶어 장기 에이전트 작업을 처리하며, 텐센트 라인업 가운데 처음으로 컴퓨터 사용(computer use) 기능을 지원합니다. 8월 28일 나온 Hy4 프리뷰는 총 7,700억 개 매개변수 중 490억 개가 활성화되는 구조이고, 두 모델 모두 100만 토큰 컨텍스트를 지원합니다. 텐센트는 프리뷰 대비 GameDev 벤치마크에서 19.1%, GameLogic에서 9.8% 개선됐다고 밝혔지만 기준 점수는 공개하지 않았습니다. API 가격은 입력 100만 토큰당 약 0.9달러, 출력 2.7달러, 캐시 입력 0.045달러로 프리뷰와 같습니다. 텐센트 클라우드 TokenHub, 위안바오, 위챗 업무용 앱(WeCom) AI 비서 등에 적용됐고 OpenRouter로도 쓸 수 있습니다. 경량판 Flash와 가중치·시스템 카드도 곧 공개할 예정이지만 날짜는 밝히지 않았습니다. 같은 날 제프리스는 텐센트에 대한 '매수' 의견과 목표가 711홍콩달러를 유지했습니다. ### 코그니션 'SWE-2 Flash': SWE-2보다 3배 빠르고 가격은 5분의 1

데빈(Devin)을 만든 코그니션이 11월 4일 코딩 에이전트 모델 SWE-2 Flash를 공개했습니다. 싱킹머신즈의 Inkling-Small(총 2,760억, 활성 120억 매개변수)을 기반으로 후속 학습했으며, 회사는 SWE-2 대비 "가격은 5분의 1, 속도는 3배"라고 설명합니다. 데모 비교에서는 초당 200토큰 대 60토큰으로 재생했습니다. 기반 모델 대비 개선 폭은 터미널벤치 4.0에서 0.9%→20.0%, FrontierCode 2.0에서 3.2%→24.0%, ExploitBench에서 11.3%→34.8%입니다. 다만 터미널벤치 4.0 점수는 SWE-2(27.3)보다 낮아, 최고 성능보다는 빠르고 저렴한 반복 작업용에 가깝습니다. 데빈 데스크톱과 CLI에서 11월 30일까지 무료로 쓸 수 있고, 가중치는 공개하지 않은 채 신뢰할 수 있는 파트너에 공유하는 프로그램을 준비 중이라고 밝혔습니다.
