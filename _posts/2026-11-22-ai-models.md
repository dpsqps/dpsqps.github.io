## 텍스트 밖으로: 음성과 움직이는 이미지에서 나온 모델 업데이트

주말을 앞두고 대형 언어 모델 신작은 없었지만, 음성과 영상 쪽에서 실사용에 가까운 업데이트가 나왔습니다. OpenAI는 음성 모델의 새 버전을 API로 풀면서 '말하지 않는 시간'의 요금을 낮췄고, 구글은 영상 모델을 이용한 GIF 생성을 제미나이 앱에 넣었습니다.

### OpenAI 'GPT-Live-1.1' API 출시: 대기 중 요금은 분당 0.02달러로 60% 저렴

OpenAI가 19일(현지시간) 개발자 커뮤니티를 통해 음성 모델 'GPT-Live-1.1'을 API로 제공한다고 밝혔고, 국내에는 22일 보도됐습니다. 이전 버전인 GPT-Live-1과 비교해 여러 언어에서 억양이 더 자연스러워졌고, 문자와 숫자를 다루는 정확도와 지시 이행 능력이 개선됐다는 설명입니다. 듣기와 말하기를 동시에 처리하는 전이중(full-duplex) 음성을 지원합니다.

함께 나온 '대기(Standby)' 옵션이 요금 구조를 바꿉니다. 개발자가 5~60초 범위에서 유휴 시간을 정해두면, 그 시간이 지난 뒤에는 추론이 멈추고 WebRTC 연결과 대화 기록만 유지됩니다. 대기 상태 요금은 분당 0.02달러로, 활성 상태의 분당 0.05달러보다 60% 낮습니다. 백엔드 모델과 도구 사용 비용은 별도로 청구되며, 대기 옵션은 GPT-Live-1과 1.1 모두에 적용됩니다. GPT-Live-1.1은 10월 15일부터 ChatGPT 플러스·프로의 음성 기능에 먼저 쓰여 왔습니다. OpenAI는 다국어 음성 지원, 이름·인증번호를 정확히 받아야 하는 고객 상담, 통화 시간이 긴 전화 기반 에이전트를 활용 사례로 제시했습니다. 통화가 길수록 침묵 구간이 길어지는 음성 에이전트의 특성상, 성능보다 과금 방식 변화가 실제 운영비에 더 크게 작용할 수 있습니다. ### 구글, 제미나이 앱에 GIF 생성 기능: 영상 모델 'Gemini Omni 1.2 Flash'로 약 3초 루프

구글이 20일(현지시간) 공식 X 계정을 통해 제미나이 앱의 GIF 생성 기능을 발표했습니다. 영상 모델 'Gemini Omni 1.2 Flash'를 기반으로 하며, 텍스트 프롬프트를 넣으면 약 3초 길이의 반복 재생 애니메이션이 만들어지고 복사하거나 .gif 파일로 내려받을 수 있습니다. 출시 지역은 미국·캐나다·영국·일본·한국·호주·독일·프랑스 8개국이고, 구글은 무료와 유료 사용자 모두 쓸 수 있다고 밝혔습니다. 보도에 따르면 OpenAI가 ChatGPT에 GIF 생성을 넣은 지 16일 만의 대응입니다. 다만 개발자용 API는 공개되지 않았고, 해상도·파일 크기·생성 횟수 제한도 공개되지 않았습니다. 긴 영상 생성 경쟁과 별개로, 메신저에서 바로 쓰는 짧은 결과물이 소비자 앱의 기본 기능으로 자리 잡는 흐름입니다.
