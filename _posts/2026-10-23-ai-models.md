## 작고 싸고 특화된 모델들: 노트북 코딩부터 음성·로봇 데이터까지

오늘 모델 소식은 '최고 성능'보다 '특정 작업에 맞춘 효율'에 무게가 실렸습니다. 노트북에서 돌아가는 코딩 MoE, 1초 안에 대화 한 턴을 처리하겠다는 음성 모델군, 로봇 영상 주석 비용을 100배 넘게 낮춘 모델이 나란히 공개됐습니다.

### 리커시브 '플린트': 활성 파라미터 25억 개짜리 로컬 코딩 MoE, 아파치 2.0 공개

리처드 소처가 이끄는 신생 기업 리커시브가 10월 21일 첫 모델 '플린트(Flint)'를 오픈 웨이트로 내놨습니다. 총 400억 파라미터 MoE 구조지만 토큰당 활성 파라미터는 약 25억 개에 불과해, M4 Pro 맥북 프로에서 초당 125토큰 이상, 64GB 엔비디아 RTX 스파크에서 초당 150토큰 이상을 낸다고 회사는 밝혔습니다. 회사 자체 측정 기준 SWE-bench Pro v2 점수는 89.7%입니다. 리커시브는 AI가 개선안을 제안·구현·검증하는 자동 연구 시스템 '유레카 머신'으로 4개월이 안 되는 기간에 모델을 완성했다고 설명했습니다. 다만 성능·속도 수치는 모두 자체 보고치로 독립 검증 전입니다. [OpenHands 블로그](https://www.openhands.dev/blog/recursive-flint-on-openhands) / [Runtime Wire](https://runtimewire.com/article/recursive-flint-local-coding-model-eureka-machine) / [AI Weekly](https://aiweekly.co/alerts/recursive-opens-flint-a-40b25b-moe-coder-hitting-897-on-swe-bench-pro-v2-under)

### 미스트랄 '복스트랄 3' 제품군: 받아쓰기 오류율 2.1%, 음성 생성 첫 소리까지 약 90ms

미스트랄이 음성 인식·합성 모델과 음성 에이전트 SDK를 묶은 '복스트랄 3' 제품군을 공개했습니다. 대표 받아쓰기 모델 '스몰 트랜스크라이브 3'의 단어 오류율은 2.1%, 40억 파라미터 경량 모델 '미니 트랜스크라이브 3'는 2.2%입니다. 음성 합성 모델 '스피치 3'는 약 90ms 만에 소리를 내기 시작하며 35개 이상 언어를 지원합니다. 가격은 미니 받아쓰기가 분당 0.0035달러, 음성 생성이 100만 자당 13달러입니다. 라이브킷 기반 SDK는 전화(SIP)와 웹RTC를 지원하고, 단계별 모델을 갈아 끼울 수 있게 설계돼 대화 한 턴을 1초 안에 처리하는 것이 목표입니다. ### 엔비디아 '플로라': 로봇 영상 1시간 주석 비용 0.72달러, GPT-6 아스트라 대비 약 122분의 1

엔비디아가 로봇·사람 작업 영상에 동작 구간, 성공 여부, 실패 원인을 자동으로 달아주는 오픈 모델군 '플로라(Flora)'를 공개했습니다. 구간 분할용 90억 파라미터 모델과 캡션·보상 평가용 270억 파라미터 모델 2종으로 구성됩니다. 원본 영상 1시간당 처리 비용은 약 0.72달러로, 최대 추론 설정의 GPT-6 아스트라(약 88.49달러)보다 120배 이상 저렴하다고 엔비디아는 밝혔습니다. GB300 GPU 서버 512대로 하루 최대 20만 시간 분량을 처리할 수 있고, 로보리워드 평균절대오차는 40.0으로 아스트라(55.4)보다 낮았습니다. 가중치는 연구용 비상업 라이선스로 공개돼 상용 사용은 불가합니다. 휴머노이드 기반 모델 GR00T 학습 데이터 생산에 쓰입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216528)

### 미스트랄 '타임스트랄'·나세AI '드렉스 맥스': 시계열 예측과 판정 전용 모델

같은 날 공개된 특화 모델 가운데 미스트랄의 첫 시계열 예측 모델군 '타임스트랄(Timestral)'은 500만~2억900만 파라미터의 4종으로, GPU 없이 CPU에서 돌아가며 회사 자체 평가에서 공개 벤치마크 3개 1위를 기록했다고 밝혔습니다. 나세AI의 멀티모달 판정 모델 '드렉스 맥스'는 요청당 질문 16개·이미지 8장까지 처리하고 입력 100만 토큰당 0.06달러, 출력 토큰은 별도 과금이 없습니다. 범용 LLM에 맡기던 수요 예측이나 영수증 판별 같은 반복 업무를 작고 싼 전용 모델로 떼어내는 흐름입니다.
