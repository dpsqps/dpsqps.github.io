## 브라우저 속으로 들어온 에이전트, 그리고 코딩 도구의 '기본값' 전쟁

이번 주말 도구 소식은 에이전트가 사용자의 브라우저 탭을 직접 다루기 시작한 변화, 코딩 플랫폼의 기본 모델 교체, 그리고 에이전트 도구가 늘면서 커진 API 키 탈취 위험으로 요약됩니다.

### 오픈AI, 크롬용 챗GPT 확장에 '작업 모드': 열린 탭을 읽고 직접 조작

오픈AI는 10월 15일(현지시간) 크롬용 챗GPT 확장 프로그램을 강화해, 열어 둔 여러 탭의 내용을 한꺼번에 분석하고 탭을 직접 제어해 작업하도록 했습니다(AI타임스 10월 17일 보도). 확장은 **2가지** 모드로 나뉩니다. 채팅 모드는 페이지를 읽고 답하며, 작업(Work) 모드는 탭을 조작해 양식 작성·자료 정리·탭 그룹화 등을 수행합니다. 입력창에 '@chrome'을 넣으면 열린 탭을 요청 대상으로 지정할 수 있고, 탭 제어를 쓰려면 챗GPT 데스크톱 앱의 '설정 → 컴퓨터 사용'에서 크롬을 연결해야 합니다. 오픈AI가 든 예시에는 여러 상품 페이지의 크기·소재·배송·반품 조건 비교표 작성, 행사 안내문으로 등록 양식을 채운 뒤 제출 직전에 멈추기 등이 있습니다. 대상 요금제와 지원 지역은 공개되지 않았습니다. 별도 에이전트 브라우저가 아니라 사용자가 이미 쓰는 크롬 안에서 에이전트를 돌린다는 점이 차이입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216360)

### 레플릿, 기본 모델을 클로드에서 챗GPT로: "엔터프라이즈 매출 비중 2% → 15%"

레플릿의 암자드 마사드 CEO는 테크크런치 디스럽트 무대에서 회사가 더 이상 앤트로픽과 일하지 않는다고 말했고, 이후 "클로드는 계속 선택 가능하지만 레플릿 에이전트의 기본값은 챗GPT"라고 정정했습니다(테크크런치 10월 17일 보도). 그는 비용·파트너십·성능을 이유로 들며 오픈AI 모델이 처음부터 앱을 만드는 바이브 코딩에서 더 낫다고 주장했습니다. 레플릿은 최근까지 앤트로픽의 **상위 5개** 고객이었고, 대부분 사용자가 기본값을 그대로 쓰는 만큼 앤트로픽 쪽 지출은 크게 줄어들 수 있습니다. 마사드는 엔터프라이즈 매출 비중이 지난해 약 **2%**에서 올해 약 **15%**로 늘었고, B2B가 매출의 **50%** 이상이라고 밝혔습니다. 한편 레플릿 CTO는 AI가 만든 코드를 검증하려고 스타트업 앤티테시스의 결정론적 시뮬레이터로 네트워크 지연·서버 장애를 재현해 테스트한다고 밝혔습니다. 앤티테시스는 지난해 12월 시리즈 A에서 **1억 500만 달러**를 유치했습니다. 코딩 플랫폼에서 모델은 교체 가능한 부품이 되고, 경쟁력은 검증·실행 환경으로 옮겨 가는 모습입니다. [TechCrunch](https://techcrunch.com/2026/10/17/replit-is-no-longer-working-with-anthropic-ceo-says/) / [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216367)

### 오픈코드, '증류 공격'으로 콘솔 사용자 1.4% API 키 피해

오픈소스 코딩 에이전트 오픈코드(OpenCode)는 10월 17일 피해 계정에 이메일을 보내, 대규모 '증류(distillation) 공격'으로 콘솔 사용자의 **1.4%**가 영향을 받았다고 알렸습니다. 탈취된 API 키로 무단 사용 요금이 청구됐고, 사용자들 사이에서는 키 폐기와 비밀번호 변경을 권하는 글이 퍼졌습니다. 회사는 구글·오픈AI·앤트로픽 **3사**와 함께 복구 작업을 진행 중이며, 진행 중이라는 이유로 세부 내용은 공개하지 않았습니다. 여러 모델 제공사의 키를 한곳에 모아 두는 에이전트 도구가 늘수록, 도구 하나의 침해가 여러 클라우드 청구서로 번진다는 점을 보여 준 사례입니다. [HuggingNews](https://huggingnews.com/cybersecurity/opencode-confirms-distillation-attack-hit-14percent-of-console-users-51c80aca)
