## 에이전트가 '고객'이 되는 도구들: 기업 플랫폼, 전용 컴퓨터, 에이전트 우선 CLI

9월 28일 발표된 도구들은 공통적으로 사람이 아닌 AI 에이전트를 1차 사용자로 상정합니다. 메타는 소비자용 에이전트를 기업 시장으로 옮겼고, 마누스와 클라우드플레어는 에이전트가 직접 쓰는 작업 환경과 명령줄 도구를 내놨습니다.

### 메타, '메타 엔터프라이즈 플랫폼' 출범 — 뮤즈를 기업용으로, MongoDB 전 CEO 영입

메타는 9월 28일 자사 AI 모델·에이전트·개발 도구를 기업과 개발자에게 제공하는 '메타 엔터프라이즈 플랫폼'을 발표했습니다. 초기 구성은 Muse 에이전트, Meta Business Agent, Muse API, Muse Code 4가지입니다. 기존 Business Agent는 왓츠앱·메신저에서 고객 문의 응대, 상품 추천, 예약, 판매까지 처리하며 6월 기준 100만 개 이상 기업이 사용 중이라고 밝혔습니다. 사업 총괄로는 MongoDB CEO 출신 CJ 데사이(Chirantan Desai)가 최고 엔터프라이즈 플랫폼 책임자로 합류해 저커버그에게 직접 보고합니다. 저커버그는 이를 "사업의 다음 주요 기둥"이라고 표현했습니다. 가격과 정식 출시일은 공개되지 않았습니다. 뮤즈 출시 약 3주 만에 기업 시장으로 확장하면서 오픈AI·앤트로픽·구글과 기업 에이전트 시장에서 정면 경쟁하게 됐습니다. [Meta Newsroom](https://about.fb.com/news/2026/09/launching-meta-enterprise-platform/) / [Techloy](https://www.techloy.com/meta-enterprise-platform-muse-ai/)

### 마누스 2.0 — 'Cascade' 구조로 비용 32% 절감, 에이전트에 이메일·전용 컴퓨터 부여

마누스는 9월 28일 '마누스 2.0'을 공개했습니다. 새 기반 구조 'Cascade'는 이전 대비 토큰 사용량 23.2%, 작업 시간 28.2%, 실행 비용 32%를 줄였다고 회사는 밝혔습니다. 상시 실행이 필요한 작업을 위한 전용 '클라우드 컴퓨터', 이메일·캘린더·슬랙 이벤트로 시작되는 자동화, 30~60초 영상 편집·멀티플레이 게임 제작 환경을 갖춘 'Manus Studio'가 추가됐습니다. 별도 앱 'Cue'는 개인 에이전트에게 고유 이메일 주소 등 독립된 신원을 부여하며, 초대 코드 기반 얼리 액세스로 제공됩니다. 에이전트가 사람의 계정을 빌리는 대신 자기 신원을 갖고 외부와 상호작용하는 방향으로 이동하고 있음을 보여줍니다. [Manus Blog](https://manus.im/blog/introducing-manus-2-0)

### 클라우드플레어 'cf' CLI — API 3,000개 이상을 에이전트용으로, Wrangler 사용의 48%가 이미 에이전트

클라우드플레어는 9월 28일 AI 에이전트를 주 사용자로 설계한 새 명령줄 도구 'cf'를 오픈 베타로 공개했습니다(`npm i -g cf`). 기존 Wrangler가 약 280개 API 작업을 지원한 데 비해 cf는 3,000개 이상을 다루며, 기본 출력은 JSON, 설정은 TypeScript(`cloudflare.config.ts`)입니다. 회사에 따르면 Wrangler 사용의 48%가 이미 에이전트에서 발생하고 있고, 에이전트 사용자는 사람보다 하루 약 2배 많은 종류의 명령을 호출합니다. API 스키마에서 SDK·CLI·MCP 서버를 생성하는 내부 도구 'Forge'도 오픈소스로 공개했습니다. [Cloudflare Blog](https://blog.cloudflare.com/cloudflare-cf-cli-launch/) / [Cloudflare Blog — Forge](https://blog.cloudflare.com/forge-open-source-generation-pipeline/)

### 신세계I&C, 메타 AI 글래스 국내 출시 — 9개 모델 21종, 48만~86만 원

메타 기기 국내 공식 유통사 신세계I&C는 9월 28일 메타 AI 글래스 신제품을 국내에 출시했습니다. 9개 모델 21종으로, 신규 메타 브랜드 제품 'Meta Capri'·'Meta Nova', 레이밴 메타 3세대, 블랙핑크 리사 협업 에디션(64만 원) 등이 포함됩니다. 가격은 모델·렌즈에 따라 48만~86만 원이며, 레이밴 메타 3세대는 최대 9시간 배터리를 제공합니다. 이마트·롯데하이마트·SSG닷컴·SK텔레콤·KT 온라인몰 등에서 판매됩니다. 뮤즈 에이전트는 아직 국내 미출시인 가운데, 메타의 AI 하드웨어가 먼저 한국 소비자 접점을 넓히는 셈입니다. [뉴스핌](https://www.newspim.com/news/view/20260928000701)
