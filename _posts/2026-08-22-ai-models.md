## 모델 자체보다 '모델을 감싼 것'이 점수를 만든 하루

8월 21일 공개된 세 건은 공통점이 있다. 새 파라미터를 늘려 이긴 사례가 하나도 없다. 시각 입력을 붙이거나, 기존 모델을 루프로 감싸거나, 컨텍스트를 100만 토큰까지 열어 무료로 뿌리는 방식으로 성능과 경제성이 움직였다.

### 딥시크 V4-Flash-Vision-Exp — 이미지 1,000장 처리에 1.15위안

딥시크는 8월 21일 API 플랫폼에 실험적 멀티모달 모델 `deepseek-v4-flash-vision-exp`를 올렸다. 텍스트 능력은 기존 V4-Flash와 동급을 유지하면서 시각 이해가 필요한 에이전트 과제에서 큰 폭으로 올라섰다는 설명이다. 자체 측정 기준으로 Terminal Bench 2.1은 83.9점(V4-Flash-0731 82.7, Opus 4.8 85.0), ApexBench pass@1은 36.5점(텍스트 전용 V4-Flash 26.2, Opus 4.8 39.4)이다. Agents' Last Exam 27.3점과 ZeroBench pass@5 35.0점은 각각 Opus 4.8의 25.7점·34.0점을 앞섰고, NL2Repo는 57.7점으로 Opus 4.8의 69.7점에 뒤졌다.

가격 구조가 더 눈에 띈다. 이미지는 장당 최대 384토큰으로 환산해 V4-Flash와 동일 단가로 과금한다. 1,000장 처리 비용이 약 1.15위안(약 0.17달러), 오프피크 시간대에는 0.6위안 아래로 떨어진다. 오픈라우터 기준 단가는 입력 100만 토큰당 0.22달러, 출력 0.66달러다. 같은 날 이미지를 한 번 올려 `file_id`로 재참조하는 Files API도 무료로 함께 열렸다. 다만 벤치마크는 딥시크가 자체 환경에서 측정한 값으로, 독립 검증을 거치지 않았다. [DeepSeek API Docs](https://api-docs.deepseek.com/news/news260821/) / [OfficeChai](https://officechai.com/ai/deepseek-releases-v4-flash-vision-exp-matches-opus-4-8-on-some-multimodal-benchmarks/)

### 엔비디아 AVO, ARC-AGI-3에서 100% — 같은 모델 단독으로는 30%

엔비디아는 8월 21일 자사 범용 코딩 에이전트 AVO(Agentic Variation Operators)가 ARC-AGI-3 상호작용 추론 벤치마크에서 25개 공개 환경의 183개 레벨을 전부 통과해 100%를 기록했다고 발표했다. 지시문도, 명시된 규칙도, 목표도 주어지지 않은 상태에서의 결과다. 핵심은 AVO를 구동한 모델이 앤트로픽 클로드 오퍼스 5라는 점이다. 같은 모델을 단독으로 돌리면 같은 벤치마크에서 약 30%에 머문다. 지속 메모리, 점검-계획-구현-평가 반복 루프, 막혔을 때 경로를 되돌리는 감독 모듈이 30%를 100%로 바꿨다.

원래 자율 소프트웨어 엔지니어링과 CUDA GPU 커널 최적화를 위해 만든 시스템이라는 점도 시사적이다. 단, 이 수치는 엔비디아가 자체 재구현한 과제 인터페이스에서 자체 측정한 값이며 ARC Prize 공식 리더보드의 독립 검증을 거치지 않았다. [NVIDIA Technical Blog](https://developer.nvidia.com/blog/nvidia-avo-reaches-100-on-arc-agi-3-demonstrating-a-frontier-level-general-purpose-architecture-for-long-horizon-autonomous-agents/) / [The New Stack](https://thenewstack.io/nvidia-avo-arcagi3-benchmark/)

### 정체불명 'Ox Alpha' — 100만 컨텍스트를 일주일간 무료로

제조사가 공개되지 않은 스텔스 모델 Ox Alpha가 오픈라우터에 `stealth/ox-alpha`로, 그리고 OpenCode에 등록돼 약 일주일간 무료로 풀렸다. 컨텍스트 창은 1,048,576토큰, 최대 출력은 131,072토큰이며 텍스트·이미지·영상 입력을 받는다. OpenCode 측은 데이터 무보관에 "사실상 무제한 사용"이라 부를 만한 레이트 리밋을 걸었고, 하루 100조 토큰 처리 용량을 확보했다고 밝혔다. 오픈라우터 설명은 코딩과 장기 지속 에이전트 작업, 프로덕션 워크로드를 겨냥한 추론 모델이라고 소개한다. 어느 랩이 만들었는지는 확인되지 않았고, 커뮤니티의 지문 분석은 중국계 랩을 지목하고 있다. [OfficeChai](https://officechai.com/ai/stealth-model-ox-alpha-available-for-free-for-a-week-on-openrouter-and-opencode/) / [OpenCode (X)](https://x.com/opencode/status/2090544355824038300)
