## 글을 쓰지 않는 모델, 말을 하는 모델 — '결정 모델' 오픈소스 경쟁과 실시간 음성 신형

10월 1~2일 모델 소식은 두 갈래였습니다. 텍스트를 생성하는 대신 정해진 선택지에 확률을 매기는 '결정 모델'이 클라우드플레어와 아마존에서 잇따라 오픈소스로 나왔고, 마이크로소프트와 일레븐랩스는 지연시간 0.1초대의 실시간 음성 모델을 내놓았습니다.

### 클라우드플레어 'Clef'·'Clef-flash' 공개 — 중앙값 38.8ms, Apache 2.0

클라우드플레어가 10월 1일 자사 첫 오픈소스 결정 모델 Clef와 Clef-flash를 공개하고 Workers AI에 올렸습니다. Clef는 Qwen 3.8-27B를, Clef-flash는 Qwen 3.5-9B를 기반으로 하며, 컨텍스트 창은 64k 토큰으로 타입세이프(TypeSafe)의 결정 모델 Jev(32k)의 두 배입니다. 회사가 공개한 지연시간 중앙값은 Clef 209.3ms, Clef-flash 38.8ms로 Jev의 524.1ms보다 짧습니다. 정확도는 벤치마크마다 엇갈립니다. BFCL에서는 Clef가 98.47로 Jev(95.75)를 앞섰고 API-Bank에서는 Clef-flash가 93.11로 Jev(88.19)를 앞섰지만, When2Call에서는 Jev가 80.97로 Clef(72.37)보다 높았습니다. 모든 수치는 클라우드플레어 자체 측정값이며 독립 검증은 아직 없습니다. 가중치는 Apache 2.0 라이선스로 허깅페이스에 공개됐고, 강화학습 미세조정 서비스는 당분간 클라우드플레어 엔지니어 팀을 통해서만 제공됩니다. [Cloudflare Blog](https://blog.cloudflare.com/clef-decision-models/)

### 아마존 'Strands Decider 2B' — 20억 파라미터짜리 Jev 대항마

같은 날 아마존웹서비스(AWS)의 Strands Labs도 오픈소스 결정 모델 Strands Decider 2B를 공개했습니다. Qwen3.5-2B를 기반으로 한 20억 파라미터 모델로, AWS 엔지니어 마크 브루커가 주도한 프로젝트입니다. 테크크런치에 따르면 이 모델은 동급 크기 모델 가운데 Jevbench 순위 1위에 잠시 올랐습니다. 결정 모델은 문장을 만들지 않고 워크플로 한 단계에서 필요한 선택과 신뢰도 점수만 돌려주는 구조입니다. 타입세이프가 Jev를 내놓은 뒤 연구자들이 유사 모델 수십 종을 만들었고, 이번 주에는 오픈AI도 같은 유형의 API를 내놓았습니다(오픈AI Decisions API는 전일 다룬 내용의 후속 흐름입니다). 클라우드플레어와 아마존이 같은 날 가세하면서 2B·9B·27B 크기의 공개 가중치 선택지가 한꺼번에 생겼습니다. [TechCrunch](https://techcrunch.com/2026/10/01/amazon-releases-its-own-jev-clone-as-decision-models-flood-the-web/)

### 마이크로소프트 MAI 음성 3종 — 스트리밍 전사 단어 오류율 2.5%

마이크로소프트 AI는 10월 1일 첫 스트리밍 전사 모델 MAI-Transcribe-2-Streaming과 음성 합성 모델 MAI-Voice-2.1, MAI-Voice-2.1-Flash를 Microsoft Foundry에 출시했습니다. 전사 모델은 60개 언어를 자동 감지하며, 최종 단어 오류율(WER) 2.5%로 비교 대상 38개 모델 중 1위를 기록했다고 회사는 밝혔습니다. 발화가 끝난 뒤 최종 텍스트가 돌아오기까지 약 0.13초가 걸립니다. 가격은 연말까지 오디오 1시간당 0.54달러입니다. MAI-Voice-2.1은 23개 언어를 한 목소리로 오가며 말할 수 있고 100만 자당 22달러입니다. Flash 버전은 엔드투엔드 지연 150ms로 대량·저지연 작업용입니다. [Microsoft AI](https://microsoft.ai/news/our-first-streaming-transcription-model/) / [Unite.AI](https://www.unite.ai/microsoft-launches-mai-transcribe-2-streaming-and-two-mai-voice-models/)

### 일레븐랩스 '일레븐 v4' — 지원 언어 70개→90개 이상, 터보는 평균 100ms

일레븐랩스는 감정 표현을 강화한 음성 합성 모델 '일레븐 v4'와 실시간 대화용 '일레븐 v4 터보'를 출시했습니다. 지원 언어는 기존 70개에서 90개 이상으로 늘었고, v4 터보는 첫 응답 생성까지 평균 약 100ms가 걸립니다. v4는 어조·속도·인물 성격을 해석해 발화하며, 자연어 지시나 [웃음] 같은 태그로 말하는 방식을 지정할 수 있습니다. 음성 도용을 막는 Voice CAPTCHA와 No-Go Voices 기능도 포함됐습니다. 마이크로소프트의 Flash(150ms)와 하루 차이로 나온 만큼, 실시간 음성 에이전트 시장의 지연시간 기준선이 0.1초대로 내려왔다고 볼 수 있습니다. [베타뉴스](https://www.betanews.net/article/view/beta202610020045)
