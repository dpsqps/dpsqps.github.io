## 사전학습 없이 성능을 올리고, 같은 칩으로 값을 내린다

이번 주 모델 발표의 공통점은 "더 큰 모델"이 아니라 "같은 연산으로 더 많은 지능"이다. 딥시크는 사후학습만 다시 돌려 에이전트 점수를 끌어올렸고, 오픈AI는 추론 시스템 최적화만으로 API 가격을 최대 80% 내렸다.

### 딥시크 V4-Flash-0731: 사후학습만 다시 돌려 DeepSWE 7.4점 → 54.4점

딥시크가 8월 1일 'DeepSeek-V4-Flash-0731'을 퍼블릭 베타로 공개했다. 전체 매개변수 2,840억 개 중 추론 시 활성화되는 것은 130억 개뿐인 MoE 구조이며, 컨텍스트는 최대 100만 토큰을 지원한다. 주목할 점은 사전학습을 다시 하지 않고 **사후학습(post-training)만 재수행**했는데도 에이전트 지표가 크게 뛰었다는 것이다. 코드 리포지토리 과제인 DeepSWE는 이전 7.4점에서 54.4점으로 7배 이상 올랐고, 터미널벤치 2.1은 82.7점, NL2Repo 54.2점, Cybergym 76.7점, 아티피셜 애널리시스 IQ 50점을 기록했다. 가격은 입력 100만 토큰당 0.14달러, 출력 0.28달러이며 캐시 적중 시 0.0028달러로 약 98% 저렴해진다. 출력 토큰 사용량도 12% 줄어, 같은 작업을 시키면 표기 단가보다 실제 청구액이 더 낮아지는 구조다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=213429)

### 오픈AI '아스트라': 워싱턴 D.C. 비공개 시연, 수학 난제 10개 해결

오픈AI가 차세대 라인업 '아스트라(Astra)'를 개발 중이며, 샘 알트먼 CEO가 8월 1일 보도된 바에 따르면 미국 워싱턴 D.C.에서 정책 입안자·규제 당국 관계자를 상대로 비공개 시연을 진행했다. 아스트라의 핵심은 여러 AI 에이전트가 장시간 상호작용하며 복잡한 프로젝트나 고급 수학 문제를 단계적으로 풀어내는 **멀티 에이전트 협업**이다. 오픈AI는 정식 출시에 앞서 이 모델이 그동안 풀리지 않았던 수학 난제 10개를 해결한 과정을 담은 기술 보고서를 먼저 발표할 계획이다. 시연 장소와 시점이 의미심장한데, 미국 정부는 8월 초 마감 시한까지 AI 규제 프레임워크를 확정할 계획이라 제품 공개 자체가 규제 협상 카드로 쓰이는 모양새다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=213427)

### GPT-5.6 루나 API 가격 80% 인하 — '컴퓨트 멀티플라이어'

오픈AI가 7월 31일 GPT-5.6 라인업의 API 가격을 대폭 내렸다. GPT-5.6 루나는 **80% 인하**, 테라는 20% 인하다. 회사는 이것이 마케팅용 출혈 경쟁이 아니라 '컴퓨트 멀티플라이어'라 부르는 추론 시스템 최적화의 결과라고 설명했다. 실제로 GPT-5.6 솔 개발 과정에서 서빙 비용은 약 20% 감소했고 토큰 생성 효율은 15% 이상 향상됐다. 경쟁의 기준선이 "누가 더 좋은 모델을 만드느냐"에서 "같은 컴퓨팅으로 얼마나 많은 지능을 뽑아내느냐"로 옮겨가고 있다는 신호다. 같은 날 나온 딥시크의 저가 공세와 겹쳐 읽으면, 프런티어 모델의 토큰 단가는 당분간 한 방향으로만 움직일 가능성이 크다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=213385)

### 구글 딥마인드 '제미나이 로보틱스 2': 전구 제거 성공률 92%, 손가락 22자유도

구글 딥마인드가 7월 31일 휴머노이드 전신 제어 AI '제미나이 로보틱스 2'를 공개했다. 기존 모델이 상체 조작에 머물렀던 것과 달리, 시각 정보와 자연어 명령만으로 걷기·장애물 회피·정밀한 손가락 움직임까지 통합 제어한다. 손은 5개 손가락에 **22개 자유도**를 갖췄고, 전구 제거 같은 정밀 조작 작업 성공률은 92%를 기록했다. 영상 이해 쪽에서는 작업 진행 상황 분류 정확도 57.4%, 특정 이벤트를 짚어내는 모멘트 파인딩 정확도 91.3%다. 개발자용 '제미나이 로보틱스 ER 2'는 구글 AI 스튜디오와 API로 제공되고, 나머지 모델은 초기 접근 파트너와 100개 이상 테스트 기업에 우선 공개된다.
