## 작은 모델은 검색 에이전트로 4배 큰 모델을 넘었고, 프런티어 연구소 직원들은 최강 모델 공개를 걱정한다

오늘 모델 소식은 방향이 서로 다른 두 가지입니다. 일본 사카나AI는 300억 파라미터 모델로 4배 큰 엔비디아 모델의 평균 점수를 넘었다고 발표했습니다. 같은 날 OpenAI와 앤스로픽 내부에서 미공개 최상위 모델을 안전하게 공개할 수 있느냐는 회의론이 커지고 있다는 보도가 나왔습니다.

### 사카나AI 'Namazu Small': 30B 추론 모델, BrowseComp 73.5점으로 Nemotron 3 Super의 2배

사카나AI는 11월 25일 300억(30B) 파라미터 추론 모델 'Sakana Namazu Small'을 공개했습니다. 엔비디아 Nemotron 3 Nano의 사전학습 베이스 모델에 사카나가 직접 추가 사전학습과 사후학습을 더했습니다. 회사 발표에 따르면 25개 벤치마크 평균에서 기반 모델인 Nemotron 3 Nano(30B-A3B)는 물론, 약 4배 크기인 Nemotron 3 Super(120B-A12B)도 앞섰습니다.

가장 크게 오른 것은 웹 검색 에이전트 능력입니다. BrowseComp는 Nano 29.3점, Super 36.1점인데 Namazu Small은 73.5점입니다. 일본어 장문 평가 LLM-jp LongBench도 67.0점(Nano)에서 86.0점으로 올랐습니다. 반대로 지식 회상형 과제는 오히려 떨어졌습니다. SimpleQA Verified는 6.8점으로 Super(18.1점)보다 낮고, HealthBench도 40.6점으로 Super(53.7점)에 못 미칩니다. 사카나도 지식 과제에서는 큰 개선이 없었다고 밝혔습니다. 파라미터에 지식을 많이 담기보다 검색과 추론을 맡기는 쪽으로 작은 모델을 키운 설계라는 뜻입니다. 공개 가중치나 API는 아직 없으며, 온프레미스 제공 상세 내용은 2026년 12월 전반에 발표할 예정입니다. [Sakana AI](https://sakana.ai/namazu-small/) / [explainx.ai](https://explainx.ai/blog/sakana-namazu-small-30b-nemotron-reasoning-november-2026)

### OpenAI·앤스로픽 직원들 "미공개 최상위 모델, 안전하게 공개하기 어렵다": 취재원 20여 명

대만 디지타임스는 11월 25일 Axios의 11월 24일 보도를 인용해 이렇게 전했습니다. 앤스로픽과 OpenAI 직원 다수가 회사의 가장 강력한 미공개 모델을 안전하게 공개할 수 있다고 더는 믿지 않는다는 내용입니다. Axios는 20명이 넘는 취재원을 근거로 들었습니다.

공개된 모델의 성능 경쟁이 아니라 공개 전 단계의 모델이 기준선을 넘었는지를 연구소 안에서 문제 삼고 있다는 점이 새롭습니다. 앞으로 모델 발표 주기나 단계적 공개 방식에 영향을 줄 수 있습니다. 같은 날 앤스로픽 CEO 다리오 아모데이는 인간 통제권을 AI에 넘기려 한다는 비판을 반박하면서, 재귀적 자기개선(RSI)에는 한계를 둘 필요가 있다는 입장을 밝혔습니다.
