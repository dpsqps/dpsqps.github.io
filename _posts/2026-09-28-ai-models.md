## 중국발 '100만 토큰' 경쟁: 풀 어텐션을 버린 오픈 MoE와 조용히 풀린 코딩 모델

9월 27일 중국 AI 기업 두 곳이 거의 동시에 새 모델을 내놨습니다. 두 모델 모두 긴 컨텍스트를 싸고 빠르게 처리하는 데 초점을 맞췄고, 기존의 '풀 어텐션' 구조 대신 희소(sparse) 어텐션을 택했다는 공통점이 있습니다.

### NaiveAI, 309B 오픈웨이트 MoE 'Naive-N0.5-Flash' 공개 — MIT 라이선스

베이징 스타트업 NaiveAI가 9월 27일 **총 3,090억(309B) 파라미터**, 토큰당 활성 파라미터 **155억(15.5B)**의 전문가 혼합(MoE) 모델 'Naive-N0.5-Flash'를 허깅페이스에 MIT 라이선스로 공개했습니다. 기본 컨텍스트는 **100만 토큰**입니다. 48개 레이어 중 39개는 슬라이딩 윈도 어텐션(SWA), 9개는 딥시크 희소 어텐션(DSA)으로 구성해 **풀 어텐션 레이어를 하나도 두지 않았고**, 샤오미의 오픈 모델 MiMo-V2.5를 기반으로 삼았습니다. 회사 측은 자체 추론 엔진 NaiveRT로 GPU 8장 단일 스트림에서 초당 **2,122토큰**의 디코딩 속도를 냈다고 밝혔지만, 프롬프트 처리 시간을 뺀 좁은 측정치입니다. 호스팅 API 가격은 입력 100만 토큰당 **0.60위안**, 출력 **2.60위안**입니다. 눈에 띄는 대목은 개발 방식으로, NaiveAI는 AI 모델이 코드 작성·실험 실행·결과 모니터링·개선안 제안의 상당 부분을 맡고 사람은 목표와 평가 기준, 핵심 결정을 담당했다고 설명했습니다. 다만 AI 기여도를 수치로 밝히지 않았고, 벤치마크도 모두 회사 자체 발표라 독립 검증이 필요합니다. [Runtime Wire](https://runtimewire.com/article/naiveai-naive-n05-flash-ai-model-development) / [Hugging Face](https://huggingface.co/NaiveAI/Naive-N0.5-Flash)

### MiniMax, 'M3.1-Flash-Preview'를 코딩 도구에 먼저 투입 — 추론 강도 5단계

MiniMax는 같은 날 새 텍스트 모델 'M3.1-Flash-Preview'를 자사 코딩 에이전트 'MiniMax Code'에 먼저 넣었습니다. 회사는 버그 수정부터 기능 개발까지 일상 개발용으로 만든 빠른 모델이라고 소개했습니다. 기존의 켜고 끄는 방식 대신 `low`·`medium`·`high`·`xhigh`·`max` **5단계** 추론 강도(reasoning effort) 설정을 도입했고, 기본값은 `max`입니다. 알파시그널에 따르면 현재는 MiniMax Code 접근 권한이 있는 이용자만 선택할 수 있고, 공개 API 모델 ID와 가격, 벤치마크는 아직 나오지 않았습니다. 유출된 아키텍처 메모(회사 미확인)에는 전면 희소 어텐션, 4비트 KV 캐시, 약 **250GB** 모델 크기 등이 적혀 있습니다. 가격과 재현 가능한 벤치마크가 나오기 전까지는 실제 운영 환경에 쓸 수 있을지 판단하기 어렵습니다.
