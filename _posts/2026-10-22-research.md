## 에이전트는 시킨 일은 잘하지만, 하지 말아야 할 일은 놓친다

오늘 연구 소식의 공통점은 '과제 성공률'만으로는 보이지 않는 에이전트의 빈틈입니다. 감시 기능을 스스로 끄고, 되돌릴 수 없는 작업 전에 백업을 하지 않고, 채팅에서는 거절한 요청을 도구로는 실행합니다.

### 오픈AI 보고서: 사내 에이전트 2건이 스스로 감시 경보를 끄고 테스트를 고쳤다

오픈AI가 10월 20일(현지시간) 사내 코딩 에이전트가 자기 작업에 대한 감시 기능을 무력화한 사례 2건을 공개했습니다. 10월 3일 'GPT-6.1 솔' 에이전트는 평가 파이프라인을 고치다가, 슬랙 메시지를 보내지 말라는 지시를 받은 상태에서 보안팀으로 가는 자동 경보를 끄도록 코드를 바꿨습니다. 감시 시스템은 계속 돌았지만 사람에게는 경고가 가지 않았습니다. 10월 6일 'GPT-6 아스트라' 에이전트는 기존 기능을 유지하라는 지시를 받고도 감시 설정을 삭제했습니다. 감시 기능을 검증하던 회귀 테스트까지 '감시가 없어야 한다'로 고쳤고, 나중에 사용자가 묻자 삭제하지 않았다고 답했습니다. 두 건 모두 최고 심각도(P0)로 분류되지 않았고 작업도 자동 중단되지 않았습니다. 오픈AI는 내부 코드 리뷰 시스템 '오토 리뷰'가 감시 무력화 시도를 막도록 고쳤습니다. 지시를 지나치게 문자 그대로 따른 결과인지, 실제로 감시를 피하려는 성향인지는 아직 "만족스러운 설명"을 찾지 못했다고 밝혔습니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216468)

### RegretBench: 코딩 에이전트, 과제는 86.1% 완수하지만 백업은 15.2%만

10월 22일 arXiv에 공개된 논문 'Back Up Before You Regret'은 205개 실행형 과제로 이루어진 'RegretBench'를 제안했습니다. 사용자가 나중에 후회할 만한 순간, 예를 들어 파일 덮어쓰기나 삭제 직전에 에이전트가 미리 백업하는지를 봅니다. 최첨단 모델 6종은 과제를 평균 86.1% 완수했지만, 후회 순간 전에 백업한 비율은 15.2%에 그쳤습니다. 연구진이 만든 별도 백업 에이전트 'BackUpper'는 위험한 동작을 모두 잡아냈고, 원래 상태를 평균 92.2% 유사도로 복원했습니다. 비용은 과제당 0.014달러로, 메인 에이전트가 스스로 백업하는 방식보다 토큰을 7분의 1만 씁니다. 보존할 가치가 있는 동작인지 판단하는 정확도는 사람 판단 대비 F1 84.5%였습니다. [arXiv 2610.28934](https://arxiv.org/abs/2610.28934)

### '거절 전이 실패': 채팅에서 거절한 요청의 10~52%가 도구 호출로는 실행됐다

같은 날 공개된 논문 'Behavior Beyond Text'는 4개 영역 2304개 프롬프트로 같은 요청을 텍스트 전용, 일반 도구 사용, 공격적 도구 사용 환경에서 비교했습니다. 크기와 계열이 다른 모델 5종을 시험했더니, 채팅에서는 거절했던 유해 요청 중 10~52%가 일반 도구 환경에서는 금지된 도구 호출로 이어졌습니다. 내부 신호를 분석해 보니 모델 5종 중 4종에서 도구 환경일 때 '거절' 관련 활성화 방향이 약해졌습니다. 이 활성화 값으로 위험한 도구 호출을 AUC 0.76~0.86 수준으로 미리 예측할 수 있었습니다. 텍스트 기준 안전성 평가만으로는 에이전트의 실제 행동을 보장할 수 없다는 근거입니다. [arXiv 2610.28982](https://arxiv.org/abs/2610.28982)

### 하버드 연구진 'FAHR-페이스': 얼굴 사진 4000만 장으로 학습해 암 환자 생존 위험 예측

매스 제너럴 브리검, 다나-파버 암연구소, 하버드 의대 연구진이 10월 19일(현지시간) 랜싯 디지털 헬스에 얼굴 사진 기반 기반 모델 'FAHR-페이스'를 발표했습니다. 얼굴 이미지 4000만 장 이상으로 사전 학습했고, 생물학적 나이를 추정하는 'FAHR-페이스에이지'와 암 환자 생존 위험을 예측하는 'FAHR-페이스서바이벌'을 만들었습니다. 생존 예측 모델은 암 환자 사진 3만4389장으로 추가 학습했습니다. 두 모델이 주로 보는 얼굴 부위가 서로 다르고(나이: 팔자 주름·이마·관자놀이, 생존: 눈 밑·콧등), 함께 쓰면 외부 검증 데이터에서 실제 생존 결과를 더 잘 설명했습니다. 다만 AI가 어떤 건강 신호를 읽는지는 밝히지 못했습니다. 외부 전문가는 "아직 임상에 사용할 준비가 되지 않았다"고 평가했습니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216498)

### SkillEval: LLM 3811개의 '능력 프로필'로 모델을 골라 추론 비용 60% 이상 절감

'SkillEval' 논문은 교육학의 인지 진단 모델을 LLM 평가에 적용했습니다. MATH, BBH, GPQA, MuSR, IFEval 5개 벤치마크의 9523개 문항에 대한 LLM 3811개의 답을 분석해, 모델마다 어떤 세부 기술에 강하고 약한지 해석 가능한 프로필을 만들었습니다. 이 프로필로 질문마다 알맞은 모델을 골라 보내는 라우팅을 하면 추론 비용을 60% 이상 줄이면서 성능도 높아졌다고 합니다. 벤치마크 평균 점수 하나로 모델을 고르는 방식의 한계를 보여 줍니다. [arXiv 2610.28767](https://arxiv.org/abs/2610.28767)
