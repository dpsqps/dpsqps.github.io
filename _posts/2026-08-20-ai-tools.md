## 도구가 놓이는 자리가 바뀐다 — 저장소 안쪽, 브라우저 툴바 위

오늘 도구 소식의 공통점은 'AI 기능 추가'가 아니라 **AI가 기본값인 자리로 제품을 옮기는 일**이다. 커서는 코드 호스팅 자체를 에이전트 기준으로 다시 설계했고, 구글은 검색과 크롬이라는 기존 관문 안으로 제미나이를 밀어 넣었다.

### 커서, 에이전트 중심 코드 호스팅 'Origin' 베타 공개 — 깃허브와 양방향 동기화

커서(Cursor)가 8월 17일 코드 호스팅 플랫폼 **오리진(Origin)**을 베타로 내놨다. 코드 저장, 리뷰, 풀 리퀘스트, 에이전트 작업을 한 작업 공간에서 처리하는 구조로, 저장소를 만들고 CLI로 프로젝트를 올리는 '코드베이스' 탭, 저장소 탐색과 PR 생성·리뷰·병합 기능을 담았다. 핵심은 이주 비용을 없앤 설계다. **깃허브와 양방향 동기화를 지원하며 깃허브를 여전히 '진실의 원천(source of truth)'으로 둔다** — 기업이 저장소를 옮기지 않고도 조직 단위로 붙일 수 있다. CI/CD는 버셀(Vercel), 디포(Depot), 버킷사이트(Buildkite)와 연동한다. 배포는 유료 등급 사용자에게 순차 적용되고, 기업 관리자는 접근을 끌 수 있다. 커서가 내세운 명분은 "사람 중심 코드 호스팅에서 **에이전트 중심 코드 호스팅으로의 전환**"으로, AI 생성 코드가 폭증하면서 기존 리뷰 체계가 병목이 된 상황을 겨냥한다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=214101)

### 구글, 검색·제미나이에 학습 도구 대거 탑재 — 3D 시뮬레이션과 퀴즈 자동 생성

구글은 8월 19일 검색과 제미나이 양쪽에 학생용 학습 기능을 한꺼번에 붙였다. 검색에는 복잡한 개념을 설명하는 **AI 생성 인터랙티브 비주얼과 3D 시뮬레이션**, 업로드한 PDF·슬라이드·필기에서 학습 문서를 만들어 주는 기능, "SAT 대비용으로 가장 자주 출제되는 어휘 퀴즈를 만들어 줘" 같은 요청으로 맞춤 연습 문제를 생성하는 기능이 들어갔다. 렌즈(Lens)를 통한 단계별 풀이 안내는 **향후 수 주에 걸쳐 순차 배포**된다. 제미나이 쪽에는 제미나이 라이브에서 다단계 리서치 리포트를 만들고 대화로 후속 질문을 이어가는 기능, DNA 모델 같은 **작동하는 3D 시뮬레이션**, 학습 노트북·플래시카드·연습 퀴즈를 모은 전용 학습 허브가 추가됐다. 대부분 기능은 즉시 사용 가능하다. 구글은 이를 OpenAI 및 노트(Knowt)·가우스(Gauth) 같은 교육 스타트업에 대한 대응으로 위치시켰다. [TechCrunch](https://techcrunch.com/2026/08/19/google-launches-new-study-tools-for-students-across-search-and-gemini/)

### 제미나이, 안드로이드 크롬 상단 툴바로 — 유료 등급엔 '자동 브라우징'

구글은 8월 18일(현지 시각) 안드로이드 크롬 **상단 툴바에 제미나이를 직접 넣고 미국 내 전 사용자로 확대**했다. 별도 AI 앱을 켜거나 탭을 옮기지 않고 긴 웹페이지를 요약하고, 페이지 내용을 묻고, 캘린더·킵 같은 구글 앱과 연동하며, '나노 바나나' 모델로 이미지 생성·편집까지 처리한다. 유료 등급인 **'AI 프로'와 'AI 울트라' 구독자에게는 '자동 브라우징(Auto Browse)'**이 제공되는데, 주차 예약, 재주문 상품 정보 갱신, 여행 일정 정리 같은 다단계 웹 작업을 에이전트가 대신 수행한다. 보안 측면에서 구글은 **프롬프트 인젝션 등 알려진 위협을 탐지하도록 모델을 학습시켰고**, 민감한 작업 완료 전에는 사용자 확인을 요구해 악성 웹페이지의 지시가 그대로 실행되는 상황을 막는다고 설명했다. 세계에서 가장 많이 쓰이는 브라우저와 최대 모바일 OS 안에 에이전트를 기본 탑재했다는 점에서 배포 규모 자체가 경쟁 변수다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=214118)
