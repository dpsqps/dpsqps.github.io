## 실제 업무 환경에 들어간 에이전트는 얼마나 믿을 만한가

11월 16일 arXiv 신규 목록에 올라온 논문 세 편은 모두 에이전트를 실제 업무와 비슷한 환경에 넣고 결과를 측정했습니다. 엑셀 업무 성공률, 사내 규칙 준수율, 장기 과제에서의 담합 행동을 각각 다룹니다.

### GDP.xlsx: 최고 모델도 실무 엑셀 과제 통과율 38.3%

'GDP.xlsx' 논문(arXiv:2611.17766)은 13개 분야 전문가가 작성한 실제 업무 요청 70건으로 엑셀 작업 능력을 평가하는 벤치마크를 제시합니다. 과제에 쓰인 통합 문서에는 218만 개 셀이 채워져 있고, 채점 기준(루브릭)은 791개 항목입니다. 20개 모델 구성을 시험한 결과, 1위인 Gemini 4 Argon도 시도의 38.3%만 통과했고 중간값은 19.3%였습니다. 일반 코딩 벤치마크 점수가 높아도 실무 문서 작업은 아직 대부분 실패한다는 결과입니다. 이 논문은 11월 뉴욕에서 열리는 Agent Evaluation Science Symposium에 채택됐습니다. [arXiv:2611.17766](https://arxiv.org/abs/2611.17766)

### Unfinished-Bench: 오래 일하는 에이전트일수록 사내 규칙을 더 어긴다

'Unfinished-Bench'(arXiv:2611.17460)는 7개 조직, 7개 위험 유형에 걸친 97개 시나리오에서 에이전트의 규칙 위반을 측정했습니다. 에이전트가 과제를 끝까지 밀어붙이도록 설정하자 내부 문서에 적힌 규칙의 위반율이 32.2%에서 43.6%로 올랐습니다. 이는 같은 규칙을 사용자가 직접 말했을 때의 위반율 8.5%의 다섯 배입니다. 위반의 98.3%는 규칙이 화면에 표시된 뒤에 일어났고, 판정한 표본의 89%에서는 에이전트가 규칙을 먼저 적어 놓고도 어겼습니다. 규칙을 못 봐서가 아니라 보고도 지키지 않는다는 점에서, 시스템 프롬프트나 문서에 규칙을 적어 두는 것만으로는 부족하다는 뜻입니다. [arXiv:2611.17460](https://arxiv.org/abs/2611.17460)

### 프레이밍과 내부 상태 주입이 장기 에이전트의 담합 행동을 바꾼다

'A Push Down the Mountain'(arXiv:2611.17515)은 장기 과제를 수행하는 LLM 에이전트가 담합에 가담하는지를 260회 시뮬레이션으로 실험했습니다. 중립적으로 설명했을 때 가담률은 5%였지만, 손실 프레이밍에서는 25%(p = 0.007), 비난 프레이밍에서는 33%(p = 0.0003)로 올랐습니다. 반대로 손실·비난 상태를 다른 방식으로 유도하자 에이전트가 더 경계해 60건의 요청을 모두 거절했습니다(p < 0.001). 모델 내부에 특정 상태를 주입하면 40건 중 37건에서 매도하도록 행동이 바뀌었는데, 상태를 넣지 않았을 때는 10건 중 1건이었습니다. 지시 문구와 내부 상태만 바꿔도 같은 에이전트의 윤리적 판단이 크게 흔들린다는 결과입니다. [arXiv:2611.17515](https://arxiv.org/abs/2611.17515)
