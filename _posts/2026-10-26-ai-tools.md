## 더 빠르게, 더 가까이: 50ms 추론 엔진부터 맥 로컬 AI·TV 첫 화면까지

이번 소식들은 AI를 '요청 경로 한가운데'나 '사용자 기기 안'으로 옮기는 흐름으로 묶입니다. 응답 지연을 수십 밀리초로 줄이거나, 클라우드 없이 로컬에서 돌리거나, 앱 설치 없이 TV 리모컨만으로 쓰게 하는 방식입니다.

### 리퀴드 AI '리플(RIPL)': 검색·광고·결제 경로에 넣는 50ms 미만 추론 엔진

리퀴드 AI가 22일(현지시간) 실시간 추론 엔진 '리플(RIPL, Real-time Inference Pipeline)'을 출시했고, AI타임스가 25일 보도했습니다. 자사 LFM2.5 모델(2억3000만~26억 파라미터)을 검색·광고·사기 탐지·추천·결제 같은 실시간 요청 경로에 직접 넣어, 요청부터 응답까지 전체 지연을 50ms 미만으로 맞추는 것이 목표입니다. 고객사 쇼피파이는 실제 검색 트래픽에서 추론 시간 20ms 미만을 기록했고, 기존 모델 대비 파라미터는 약 50% 적으면서 추론은 2~10배 빨라졌다고 소개됐습니다. 엔비디아 B200 한 장 기준 자체 측정에서 LFM2.5-1.2B는 vLLM 위의 큐원3.5-0.8B보다 p95 지연이 14.4~28.4배 낮았습니다. 오픈소스가 아닌 기업용 상용 제품이며 가격은 영업팀 문의 방식입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216627)

### 퍼플렉시티 '디사이더 포 맥': API 키·요금 없이 맥에서 도는 40억 파라미터 판단 모델

AI타임스가 25일 정리한 신작 목록에 따르면 퍼플렉시티는 분류·선택 작업용 소형 모델 'pplx-decider-flash-v1.2'를 맥 앱 '디사이더 포 맥'으로 내놓았습니다. 40억 파라미터 모델로 메모리 16GB 이상인 애플 실리콘 맥에서 로컬로 실행되며, 첫 실행 때 5.8GB 모델을 내려받습니다. API 키나 사용료가 필요 없다는 점이 특징입니다. 같은 목록의 '폰유즈(PhoneUse)'는 AI 에이전트가 클라우드 안드로이드폰과 실제 아이폰 화면을 읽고 탭·입력·스크롤하게 해주는 MCP/API 서비스로 소개됐습니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216628)

### 국내: LG유플러스 'U+tv 오늘일상', 앱·로그인 없이 TV 첫 화면에 생활정보

LG유플러스가 26일 U+tv 첫 화면을 개편하고 생활정보 서비스 'U+tv 오늘일상'을 출시했습니다. 실시간 방송 옆에 날씨(현재 기온·시간대별 예보·미세먼지), 주요 뉴스, 코스피·코스닥 지수, 지역 축제, 교통 통제 정보, 유튜브 추천 등을 보여주며, 앱 설치·회원가입·로그인 없이 리모컨만으로 쓸 수 있습니다. 회사가 IPTV·케이블 이용자 450명을 조사한 결과 80%가 콘텐츠 시청 외 용도로 TV를 써본 적이 있다고 답한 것이 개편 배경입니다. 구글 포토 연동 '홈 갤러리'도 추가했으며, UHD3 이상 셋톱박스부터 순차 적용됩니다.
