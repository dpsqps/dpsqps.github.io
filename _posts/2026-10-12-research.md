## 도구가 죽었을 때, 도구를 연결했을 때, 판단이 빨라졌을 때

10월 12일 arXiv cs.AI 공고분(161편)에서 고른 세 편은 에이전트의 '도구'를 세 방향에서 다룬다. 실행 시점에 고장 난 도구를 고르지 않는 검색기, 멀쩡한 도구들을 이어 붙여 피해 경로를 찾는 레드티밍, 그리고 결정을 싸고 빠르게 만들어도 과제 성공률은 오르지 않는다는 실증 연구다.

### RATED: API 장애율 30%에서 고장 도구 선택률을 86.2%에서 2.9%로

RATED(arXiv:2610.13889)는 에이전트 도구 검색의 빈틈을 지적한다. 기존 방식은 의미적 관련성을 최적화하지만, 그 도구가 실행 시점에 실제로 사용 가능한지는 보지 않는다. 저자들은 대조 학습으로 파인튜닝한 고정 듀얼 인코더(의미 매칭)에 실시간 실행 피드백으로 후보를 재순위화하는 경량 컨텍스추얼 밴딧을 결합했다. 모델을 재학습하지 않고도 런타임 도구 장애에 적응하는 구조다.

평가를 위해 오프라인 검색과 동적 신뢰성을 함께 측정하는 벤치마크 EcoAgent를 만들었다. 실제 도구 5,172개와 21만 개 이상의 질의-도구 쌍으로 구성된다. 결과 수치가 명확하다. 실제 질의에서 MRR이 ToolLLM API 검색기 대비 52.2% 상대 개선됐고, 장애율 30%의 심각한 API 중단 상황에서 고장 도구를 고르는 비율이 86.2%에서 2.9%로 떨어졌다. 추가 지연은 인코딩만 수행하는 추론 대비 1밀리초 미만이다. 나흘 전 공개된 OnTrack이 실패 궤적을 조기에 끊는 쪽이었다면, RATED는 실패할 도구를 애초에 고르지 않게 하는 쪽이다. 둘 다 1밀리초 수준의 오버헤드로 작동한다는 점이 공통적이다. [arXiv:2610.13889](https://arxiv.org/abs/2610.13889)

### X-AgentRed: 도구 의존성 그래프로 유해 경로 1.77배, 도구 커버리지 2.99배

X-AgentRed(arXiv:2610.13886)는 개인 에이전트의 위험 유형을 정면으로 다룬다. 여러 웹 서비스에서 도구를 쓰는 개인 에이전트는 사용자 요청 각각이 무해해도 행동이 결합되면서 의도치 않은 피해를 낼 수 있다. 문제는 기존 레드티밍 방법들이 익숙한 도구 조합에 치우친다는 점이다.

저자들이 제안한 자기진화 프레임워크는 도구 의존성의 방향 그래프를 구축한다. 한 도구의 실행 결과가 다른 도구의 선행 조건을 충족시키는 관계를 그리는 것이다. 이 그래프에서 경로를 샘플링해 현실적인 시나리오로 바꾸고, 실행 피드백으로 다듬는다. 피드백은 두 가지 개선을 유도한다. 도구를 교체해 새로운 유해 경로를 찾는 것과, 막힌 단계의 선행 조건을 수정해 경로가 더 멀리 진행되게 하는 것이다. 프런티어 에이전틱 모델 4종에서 유해 경로 발생률이 기존 STAC 대비 1.77배, 도구 커버리지는 평균 2.99배였다. 닷새 전 메타와 시에라가 개인 에이전트의 기업 인증을 위한 개방 표준(Personal Agent Protocol)을 발표한 것과 겹쳐 읽으면, 개인 에이전트의 신원을 증명하는 작업과 개인 에이전트가 만들 수 있는 조합 피해를 열거하는 작업이 같은 시기에 나란히 진행되고 있음을 알 수 있다. [arXiv:2610.13886](https://arxiv.org/abs/2610.13886)

### "빠른 결정이 더 나은 에이전트를 만들지는 않는다": Jev 실증 4,500회 실행

이번 주 산업 뉴스와 가장 직접 맞붙는 논문이다. arXiv:2610.13092는 LLM 기반 에이전트의 결정을 더 빠르고 저렴하게 만드는 효율적 결정 모델 Jev가 과제 수준의 효율적·신뢰성 있는 완수로도 이어지는지 검증했다. 에이전트 5종을 ALFWorld의 구현 과제와 AndroidWorld의 모바일 앱 사용 과제에 투입해 총 4,500회 실행을 측정했다.

결과는 갈렸다. Jev는 5종 모두에서 결정당 비용과 지연을 상당히 줄였지만, 과제 수준의 이득은 워크플로에 따라 달랐다. ALFWorld에서는 과제 성공률이 기준선 근처를 유지했고, 모바일 에이전트 두 종에서는 하락폭이 더 컸다. 원인으로 지목된 것은 두 가지다. 추가 추론과 상호작용이 결정 단계에서 아낀 비용을 흡수했고, 실패 복구 실패와 조기 완료 선언이 성공적 전달을 제한했다. 한 에이전트에서는 시도당 지출이 줄었는데도 성공 결과당 평균 비용이 오히려 올랐다. 지난 금요일 Jev 개발사 타입세이프 AI가 8억 7,000만 달러를 조달해 75억 달러 가치를 인정받은 것과 나란히 놓으면 대비가 선명하다. 결정 단가를 낮추는 것과 과제 성과를 높이는 것은 별개의 문제이며, 전자가 후자를 보장하지 않는다는 것이 이 실증의 결론이다. 다만 공개된 초록에는 4,500회라는 실행 규모 외의 구체적 성공률·비용 수치가 포함되지 않았다. [arXiv:2610.13092](https://arxiv.org/abs/2610.13092)
