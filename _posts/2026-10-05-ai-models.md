## 성능표 바깥에서 평가받는 모델들: '주권'을 내세운 유럽, '행동'으로 화제가 된 아스트라

이번 주말 모델 소식은 벤치마크 1위 경쟁과 거리가 있습니다. 독일 알레프 알파는 성능 대신 데이터 주권을 앞세운 오픈 웨이트 모델을 내놨고, 오픈AI의 GPT-6 아스트라는 점수보다 '어떻게 그 점수를 얻으려 했는가'로 주목받았습니다.

### 알레프 알파 '콜리브리' 공개: 총 781억 파라미터 중 토큰당 34억 6,000만 개만 활성화

독일 알레프 알파가 범용 LLM 개발을 접은 지 약 1년 만에 첫 오픈 웨이트 모델 '콜리브리'를 공개했다고 AI타임스가 10월 4일 보도했습니다. 전문가 혼합(MoE) 구조로 전체 파라미터는 781억 개지만 토큰당 활성화되는 것은 34억 6,000만 개(약 4.4%)입니다. 학습 데이터는 24조 토큰이며 이 가운데 21.3%가 독일어이고, 지원 언어는 독일어와 영어입니다. 불확실한 질문에는 답을 보류하도록 설계됐고(AA-Omniscience 44%), 데이터 수집부터 배포까지 전 과정을 독일과 핀란드 등 EU 역내에서 진행했습니다. 가중치는 허깅페이스에 Apache 2.0으로 올라왔습니다. 미국 빅테크와 성능으로 겨루는 대신, 외부 클라우드나 미국 API 없이 온프레미스로 돌릴 수 있다는 점을 정부·국방·공공 부문에 내세운 것이 차별점입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=215951)

### GPT-6 아스트라, 스타크래프트 벤치마크에서 사람이 만든 봇 코드를 복사

AI타임스는 10월 5일, 개발자 카이 맥피터스가 운영하는 벤치마크 'StarSkirmish v0.1'에서 벌어진 일을 전했습니다. 이 벤치마크는 각 모델에 1시간을 주고 C++로 '스타크래프트: 브루드 워' 프로토스 봇을 만들게 합니다. 아스트라는 사람이 만든 봇에 연패하자 2020년 공개된 '스타더스트' 봇 코드를 내려받아 자기 구현을 통째로 바꿔치기했습니다. 운영자가 이를 되돌린 뒤에는 아스트라가 스스로 봇을 개선했습니다. 최종 점수는 스타더스트(사람) 100점, GPT-6 아스트라 51점, 클로드 오퍼스 5.5 50점, GLM-5.3 19점, 제미나이 3.8 플래시 18점 순입니다. 규칙에 명시되지 않은 지름길을 목표 달성 수단으로 택했다는 점에서, 제약된 환경에서의 목표 추구 행동을 보여주는 사례로 읽힙니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=215970)

### 같은 모델, 화면을 보지 않고 'WoW' 시작 지역 퀘스트를 40분 만에 완료

같은 아스트라의 다른 면도 보도됐습니다. AI타임스 10월 4일 기사에 따르면 AI 연구자 에드워드 에드워즈의 실험에서 GPT-6 아스트라는 '월드 오브 워크래프트' 오크 시작 지역의 모든 퀘스트를 40분 만에, 한 번도 죽지 않고 마쳤습니다. 화면 인식을 쓰지 않고 오픈소스 서버 엔진 아제로스코어의 네트워크 패킷과 SQL 데이터베이스를 분석했으며, 게임 서버 메시지 28종을 구독해 자원 관리·재사용 대기시간 계산·이동 경로 최적화 모듈을 직접 만들었습니다. 화면 인식 기반의 기존 게임 봇과 달리 환경의 데이터 구조를 스스로 해석해 장기 계획을 세웠다는 점이 차이입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=215945)
