## 벤치마크 1위 대신 '실무에서 쓸 수 있는가'로 옮겨간 모델 경쟁

구글은 플래그십 모델을 일반 채널로 풀면서 순위표가 아닌 사내 코드베이스 작업 기록을 내세웠고, 오픈AI는 새 모델 대신 기본 컨텍스트 길이를 늘렸다. 마이크로소프트는 영상 생성의 고질적 약점인 물리 일관성을 '코드'로 우회하는 방법을 공개했다.

### 구글 제미나이 4 아르곤 확대 출시: 입력 2달러·출력 10달러, 12월부터 두 배

구글이 13일(현지시간) '제미나이 4 아르곤'을 구글 AI 스튜디오와 제미나이 API, 제미나이 앱, 검색의 AI 모드로 확대 출시했다. 9월 30일 일부 사이버보안 파트너에게 먼저 공개한 지 13일 만이다. API 가격은 11월 30일까지 백만 토큰당 입력 2달러·출력 10달러이고, 12월 1일부터 입력 4달러·출력 20달러로 오른다. 캐시된 입력은 95% 할인된다.

구글이 내세운 사례는 벤치마크가 아니라 자사 오픈소스 에이전트 개발 키트(ADK) 최적화 작업이다. 약 800개 파일, 20만 5000줄 규모의 파이썬 코드베이스에서 코딩 도구 '안티그래비티'로 11시간 무인 작업을 시켰고, 공개 단위 테스트 1만 6892개를 돌린 끝에 6개 최적화안이 나왔다. 이 중 실제 채택된 것은 2개였고, 4개는 오래된 데이터 반환 위험이나 비공개 구현 의존 등의 이유로 제외됐다. 채택된 변경으로 긴 세션의 메모리 내 세션 준비 시간이 약 40% 줄고 패키지 로딩이 21% 빨라졌지만, 첫 모델 요청까지 걸리는 시간은 거의 변하지 않았다는 점도 함께 공개됐다.

외부 평가는 엇갈린다. 아티피셜 애널리시스 지능 지수에서는 앤트로픽과 메타의 최신 모델에 뒤지고, 아레나.ai '에이전트 아레나' 종합 순위는 5위로 전해졌다. 구글은 과학자 1만 명에게 안티그래비티 최고 등급을 6개월간 무료 제공하고, 검증된 보안 전문가에게 일부 보안 제한을 푼 모델을 주는 '페어윈드' 프로그램을 수백 곳의 추가 파트너로 넓힌다. 1위 경쟁 대신 클라우드·검색·개발 도구에 모델을 묶는 유통 전략을 택한 셈이다. ### 오픈AI GPT-6.1 솔: 기본 컨텍스트 27만 2000 → 50만 토큰

오픈AI 제품 담당 티보 소티오는 SNS를 통해 코덱스와 챗GPT 워크에서 'GPT-6.1 솔'을 쓸 때의 기본 컨텍스트 길이를 27만 2000 토큰에서 50만 토큰으로 올렸다고 밝혔다. 약 80% 늘어난 수치이며, 지원 최대치는 100만 토큰이다. 28일 연속으로 진행 중인 코덱스 성능 개선 이벤트의 7일 차 업데이트로 소개됐다.

목적은 장시간 코딩 작업에서 컨텍스트 압축(compaction)이 일어나는 빈도를 줄이는 것이다. 압축 과정에서 세부 맥락이 빠지면 긴 작업의 연속성이 깨지는데, 기본값을 올려 이 문제를 늦춘다는 설명이다. 사용자는 설정에서 값을 직접 높이거나 낮출 수 있고, 오픈AI는 기본값을 더 늘릴 계획이라고 덧붙였다. 가격 변경은 언급되지 않았다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216196)

### 마이크로소프트 '코드 비디오 모델': 물리 법칙을 프롬프트가 아닌 프로그램으로 지정

마이크로소프트가 텍스트 프롬프트를 실행 가능한 프로그램으로 바꾼 뒤 영상을 생성하는 '코드 비디오 모델'을 공개했다. 코딩 에이전트가 물체 위치·움직임·타이밍·카메라 경로를 코드로 작성하고, 물리 방정식으로 움직임을 계산해 1분 이내에 프록시 영상과 참조 이미지를 만든다. 이후 사전 학습된 참조-영상(R2V) 모델이 프록시의 구조와 참조 이미지의 외형을 결합해 최종 영상을 생성한다. 프록시 영상을 샘플링 초기 단계에만 조건으로 쓰는 '초기 단계 조건화'는 추가 학습이 필요 없는 기법이다.

자체 벤치마크 '코드비디오벤치'에서 GPT-6 기반 구성은 85.8점을 기록해 학습 기반 최고 기준선인 VACE의 80.6점을 넘었고, Qwen-VL-3.8-27B 기반에서는 85.2점 대 74.3점이었다. 다만 점수 산정 방식은 보도에 설명되지 않았다. 코드는 깃허브에 공개됐으며, 3D·4D 재구성과 로봇 시뮬레이션, 월드 모델 학습 데이터 생성이 응용처로 제시됐다.
