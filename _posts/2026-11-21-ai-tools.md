## 싸게, 안전하게, 가까이서: 추론을 운영하는 방식에 손대는 도구들

새 기능보다 '추론을 어떻게 돌릴 것인가'에 관한 발표가 이어졌습니다. 응답을 늦게 받는 대신 요금을 깎는 옵션, 모델 내부 추론을 지키는 방어, 추론 속도를 높이는 프레임워크, 그리고 PC의 NPU에서 돌리는 로컬 추론입니다.

### OpenAI '완료 창' 옵션: 응답을 8시간 안에 받으면 API 요금 40% 할인

OpenAI가 Responses API 백그라운드 모드에 '완료 창(Completion Window)' 옵션을 공개 베타로 추가했습니다. 18일(현지시간) 발표됐고 국내에는 20일 보도됐습니다. 응답 목표 시간을 2시간으로 잡으면 표준 요금보다 30%, 8시간으로 잡으면 40% 저렴합니다. 대상은 GPT-6.2 아스트라, GPT-6.2 솔, GPT-6.1 테라, GPT-6 루나 4개 모델입니다. 기존 Flex 처리 등급을 대체하는 방식으로, OpenAI는 GPT-6.2 아스트라·솔부터 새 모델에는 Flex를 제공하지 않는다고 밝혔습니다. 여러 단계로 이어지는 에이전트 작업도 후속 요청이 완료 창 조건을 충족하면 할인이 유지됩니다. 즉시 응답이 필요 없는 배치성 에이전트 작업의 단가를 낮추는 장치입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=217632)

### OpenAI, 추론 탈취 공격 성공률 54.0%→0.2%: '적대적 증류' 방어 공개

OpenAI가 20일(현지시간) '적대적 증류 대응' 발표에서 GPT-6.2 아스트라·솔에 적용한 추론 정보 보호 기술과 내부 평가 결과를 공개했습니다. 이전 요청의 비공개 추론을 뽑아내는 공격의 평균 성공률(공격 모델 6개 기준)은 GPT-6 아스트라의 54.0%에서 GPT-6.2 아스트라의 0.2%로, 현재 처리 중인 요청의 추론을 탈취하는 공격 성공률은 22.9%에서 0.9%로 낮아졌습니다. 방어 수단은 적대적 학습, 추출 시도를 탐지하는 입력 분류기, 응답과 도구 호출 인수를 검사하는 출력 분류기, 사용자·조직·모델 계열 간 보호 추론 재사용 제한 등입니다. OpenAI는 올해 무단 증류 시도와 관련해 주간 제재 규모가 수천~수만 개 계정에 달했다고 밝혔습니다. 수치는 서로 다른 모델과 방어 체계를 비교한 OpenAI 내부 평가라는 점을 감안해야 합니다. [인공지능신문](https://www.aitimes.kr/news/articleView.html?idxno=42831)

### 모레 'TIDE': 서비스 중에 보조 모델을 계속 학습시켜 추론 처리량 최대 1.66배

국내 AI 인프라 기업 모레(Moreh)가 20일 자가 개선형 LLM 추론 프레임워크 'TIDE'를 공개했습니다. 작은 보조 모델이 여러 토큰을 먼저 제안하고 큰 모델이 한꺼번에 검증하는 '추측 디코딩'을 쓰되, 실제 추론 중 생성되는 데이터와 큰 모델의 중간 은닉 상태를 재활용해 보조 모델을 계속 개선합니다. 회사가 밝힌 결과는 추측 디코딩을 쓰지 않을 때보다 추론 처리량 최대 1.66배, 기존 온라인 학습 대비 보조 모델 학습 시간 최대 3.02배 단축입니다. 추론은 엔비디아 H100, 학습은 AMD Instinct MI250이 맡는 이기종 구성에서는 같은 자원을 추론에만 쓸 때보다 시스템 처리량이 최대 1.22배였습니다. 이 기술은 미국 시카고에서 열린 슈퍼컴퓨팅 2026에서 처음 발표됐습니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=217599)

### AMD, Unsloth Desktop에 XDNA 2 NPU 연동: 350억 파라미터 모델을 PC에서 실행

AMD가 19일(현지시간) 자사 XDNA 2 아키텍처 NPU를 로컬 AI 앱 Unsloth Desktop에 연동했다고 밝혔고, 국내에는 20일 보도됐습니다. 이 앱이 NPU를 지원하는 것은 처음입니다. 시연에서는 총 350억 개 파라미터의 Qwen 3.6 MoE 모델을 NPU에서 실행했습니다. 조건은 가볍지 않습니다. Qwen 3.6 35B A3B를 전체 컨텍스트로 돌리려면 NPU가 쓸 수 있는 메모리가 약 28GB 필요하고, Windows 기본 공유 메모리 비율 50%를 적용하면 시스템 메모리 64GB가 필요합니다. 보도 제목의 '100개 이상'은 모델 수가 아니라 Unsloth Desktop의 OpenAI 호환 API로 연결할 수 있는 앱·워크플로 수이며, Open WebUI, Cline, Visual Studio Code 등이 포함됩니다. [인공지능신문](https://www.aitimes.kr/news/articleView.html?idxno=42819)
