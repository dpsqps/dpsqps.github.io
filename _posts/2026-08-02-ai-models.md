## 엔비디아 밖에서 나온 오픈 모델, 그리고 초당 13센트짜리 2K 영상

이번 주말 공개된 두 모델은 방향이 정반대다. 하나는 학습 파이프라인 전체를 공개해 "누가 GPU를 만들었는가"를 증명하려 했고, 다른 하나는 가중치를 닫아둔 채 API 단가로 승부를 걸었다.

### AMD, Instella-MoE-16B-A3B 공개 — 인스팅트 GPU만으로 학습한 완전 개방형 MoE

AMD가 8월 1일 Instella-MoE-16B-A3B를 공개했다. 총 16B 파라미터 중 토큰당 2.8B만 활성화하는 희소 MoE 구조로, 27개 레이어에 공유 전문가 2개 + 라우팅 전문가 64개 중 6개를 선택하는 방식이다. 핵심은 학습 인프라다. 엔비디아 GPU가 아니라 AMD 인스팅트 MI300X·MI325X만으로 공개 코퍼스 7.1조 토큰을 사전학습했다.

구조적으로는 Gated MLA(Multi-head Latent Attention에 학습형 출력 게이트를 추가)와 FarSkip-Collective 연결을 도입해 **사전학습 속도 12.7% 향상, 첫 토큰 응답시간(TTFT) 최대 39.2% 단축**을 얻었다. 벤치마크 평균은 베이스 모델 기준 76.7로, 같은 급의 완전 공개 모델인 Moonlight-16B-A3B(76.2)와 SmolLM3-3B-Base(70.5)를 앞섰지만 Qwen3.5-4B-Base(79.5)에는 못 미친다. 후속학습 단계에서는 SFT 71.58 → Think 73.22로 올라가 Olmo3-7B-Think(71.97)를 넘어섰다.

주목할 부분은 공개 범위다. 사전학습·중간학습·롱컨텍스트 확장·SFT·DPO·RL까지 **모든 학습 단계의 체크포인트**와 데이터 믹스, 학습 설정, 추론 코드를 함께 배포했다. 다만 가중치는 학술·연구 용도로 제한하는 ResearchRAIL 라이선스라 상업적 드롭인 교체는 불가능하고, 실질적으로 재사용 가치가 큰 자산은 MIT 라이선스로 풀린 학습 코드베이스 쪽이다. ### MiniMax H3 — 15초 2K 클립에 스테레오 오디오까지 한 모델로

중국 MiniMax가 옴니모달 생성 모델 H3를 내놨다. 텍스트·이미지·비디오·오디오 입력을 하나의 생성 프레임워크로 묶은 모델로, 출력은 **2K 해상도, 4~15초(정수 단위) 길이, 네이티브 스테레오 사운드**를 지원한다. 입력은 참조 이미지 최대 9장, 영상 클립 3개(합계 15초 이하), 오디오 3개를 받되 총 파일 수는 12개로 제한된다.

기술적으로는 H3-VAE 토크나이저가 유효 시퀀스 길이에서 4배 이득을 만들어 2K 네이티브 생성을 감당 가능한 비용대로 끌어내렸고, 이해용과 생성용 트랜스포머를 분리해 엔드투엔드 학습 처리량을 약 30% 끌어올렸다. 기존 방식인 초해상도 후처리 대신 인컨텍스트 재생성을 써서 미세 디테일과 화면 내 텍스트를 보존한다는 점도 차별점이다.

가격은 초당 약 0.13달러로, 15초 2K 클립 한 편에 약 1.95달러 수준이다. 현재는 API 전용 출시이며 오픈 가중치는 "수일 내"라고 예고만 된 상태다. Artificial Analysis 집계 기준으로 영상 편집 항목에서는 선두지만, 텍스트→비디오와 이미지→비디오에서는 구글 Gemini Omni Flash에 뒤진다.
