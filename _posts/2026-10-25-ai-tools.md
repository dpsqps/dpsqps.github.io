## 에이전트를 '어디서, 어떻게 돌릴지'를 두고 클라우드가 판을 깐다

이번 주 구글 클라우드에서는 앤트로픽이 직접 운영하는 클로드가 정식으로 들어왔고, 구글은 에이전트 전용 실행 인프라와 터미널 도구를 함께 내놨습니다. 개인용 AI 에이전트 '뮤즈'가 일본에 상륙하면서, 네이버는 외부 에이전트를 자사 서비스에 들일지 검토하겠다고 밝혔습니다.

### 앤트로픽 '관리형 클로드', 구글 클라우드 정식 출시: 오푸스 5.5 패스트 모드 최대 2.5배 빨라

앤트로픽이 현지시간 10월 22일 구글 클라우드에서 자사가 직접 운영하는 클로드 서비스를 정식 출시했습니다. 구글 클라우드 IAM 자격 증명을 그대로 쓰므로 별도 API 키가 필요 없고, 사용료는 구글 클라우드 청구서에 합쳐져 기존 약정 금액에서 차감할 수 있습니다. 클로드 플랫폼에 새 기능이나 베타가 나오면 같은 날 이 서비스에도 들어옵니다. 장시간 실행 에이전트용 '클로드 매니지드 에이전트(베타)', 코드 실행, 컴퓨터 사용, MCP 커넥터(베타) 등이 포함됩니다. '클로드 오퍼스 5.5' 패스트 모드는 출력 속도를 최대 2.5배 높이며, 요금은 입력 100만 토큰당 8달러, 출력 100만 토큰당 40달러입니다. 앤트로픽이 데이터 처리 책임을 지는 '앤트로픽 관리형'과 구글이 데이터 처리자가 되는 '구글 관리형' 가운데 하나를 고를 수 있습니다. 데이터 저장 지역 요건이 엄격한 기업은 구글 관리형을, 최신 기능을 빨리 쓰려는 기업은 앤트로픽 관리형을 쓰는 식입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216613)

### 구글 클라우드 '에이전트 컴퓨트 엔진': 세션마다 마이크로VM, 에이전트 20만 개 실험

구글 클라우드가 현지시간 10월 22일 AGNTCon·MCPCon 행사에서 AI 에이전트 전용 실행 환경 '에이전트 컴퓨트 엔진'을 공개했습니다. 에이전트 세션마다 별도 게스트 커널과 루트 권한을 가진 마이크로VM을 배정해 서로 격리합니다. 모델을 호출하고 작업을 지휘하는 하네스는 샌드박스 밖에서 돌고, 코드·셸·브라우저 환경에는 필요한 명령만 전달됩니다. 쉬는 에이전트는 체크포인트를 남기고 멈췄다가 스냅숏으로 복원됩니다. 쿠버네티스 기반 오픈소스 버전 '에이전트 서브스트레이트'로 구글이 직접 측정한 결과, 에이전트 20만 개, 초당 500회 활성화, 일시정지·재개 500ms 미만, 기존 방식 대비 최대 10배의 컴퓨팅 밀도가 나왔습니다. 이미 사내 제미나이 업무 에이전트 운영에 쓰이고 있으며, 고객 프리뷰는 수개월 안에 열릴 예정입니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216608)

### 구글 '제미나이 API CLI' 오픈소스 공개: 에이전트가 curl 대신 쓰는 터미널 도구

구글이 현지시간 10월 23일 터미널에서 제미나이 API를 다루는 명령줄 도구 '제미나이 API CLI'를 실험적 프리뷰(0.4.x 버전)로 공개했습니다. 의존성 없는 단일 바이너리로 macOS·리눅스·윈도우를 지원하며, 아파치 2.0 라이선스입니다. 사람보다 AI 에이전트를 먼저 생각하고 만든 도구로, 에이전트가 모델 식별자를 직접 찾거나 일회성 스크립트·curl 명령을 짜지 않아도 됩니다. 나노 바나나 2.1(이미지), 제미나이 옴니 1.1 플래시(영상), 리리아 3.5(음악), 제미나이 3.8 플래시 TTS(음성)를 부를 수 있고, 네트워크 없이 요청을 검증하는 드라이런 옵션과 JSON 출력도 갖췄습니다. 구글은 클로드 코드, 코덱스, 커서 등을 호환 사례로 들었습니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216607) / [GitHub 저장소](https://github.com/google-gemini/gemini-api-cli)

### 국내: 메타 '뮤즈' 일본 출시로 첫 해외 진출, 네이버 "국내 오면 접근 허용 검토"

메타가 10월 23일 개인 AI 에이전트 '뮤즈'의 일본 서비스를 시작했습니다. 9월 북미 출시 후 한 달여 만의 첫 해외 진출입니다. 뮤즈는 이메일 작성·발송, 일정 관리, 여행 예약, 쇼핑 같은 일을 사용자를 대신해 처리하며, 일본에서는 메루카리·머니포워드 ME·티켓피아 3곳과 연동을 추진하고 있습니다. 국내 출시 일정은 나오지 않았습니다. 네이버는 뮤즈 같은 외부 에이전트가 국내에 본격 진출하면 네이버 서비스 접근 허용 여부를 따져보겠다고 밝혔습니다. 네이버는 자체 쇼핑 AI 에이전트에 올해 안에 일부 상품군 결제 기능을 시범 적용할 계획입니다. 외부 에이전트가 플랫폼에 들어오는 길을 열지 막을지가 국내 플랫폼의 새 숙제가 됐습니다. [AI타임스](https://www.aitimes.com/news/articleView.html?idxno=216600)
