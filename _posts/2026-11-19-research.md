## 에이전트의 '운영비'를 따지는 연구들: 캐시 비용, 도구 호출 수, 되돌릴 수 있는 행동, 실행 지연

11월 17일 arXiv에 제출된 논문들은 에이전트의 성능 그 자체보다 비용·지연·안전 같은 운영 문제를 정량적으로 다뤘습니다. 실제 배포 단계에서 에이전트를 얼마나 싸고 안전하게 돌릴 수 있는지가 연구 주제로 떠오르고 있습니다.

### 컨텍스트에도 값이 있다: 프롬프트 캐싱 아래에선 '컨텍스트 줄이기'가 비용을 최대 116% 늘린다

'Context Has a Price' 논문은 오픈 모델로 2만 회 이상의 코딩 에이전트 실행을 분석했습니다. 관련 코드를 미리 찾아 넣어 주면 읽기·검색 명령이 18~34% 줄지만, 캐시된 토큰을 10분의 1 가격으로 과금하는 환경에서는 오히려 비용이 33~42% 늘었습니다. 오래된 관찰 기록을 지우는 방법은 캐시 할인이 없을 때 비용을 19~36% 줄이지만, 10분의 1 가격 캐시가 있으면 비용을 38~116% 끌어올렸습니다. 컨텍스트 앞부분이 바뀌면 캐시가 깨지기 때문입니다. 흔히 쓰는 '컨텍스트 압축' 기법이 요금 체계에 따라 역효과를 낼 수 있다는 점을 수치로 보여 줍니다. [arXiv 2611.22238](https://arxiv.org/abs/2611.22238)

### JET: 탐색을 '필요한 만큼만', 도구 호출 11~33% 절감

'JET(Just-Enough Exploration Tuning)'는 저장소 단위 질의응답에서 도구 호출 에이전트가 불필요한 탐색을 줄이도록 학습시키는 기법입니다. 80억 파라미터 오픈 웨이트 모델 2종으로 실험한 결과, 자체 생성 궤적 기준 도구 호출을 11~33% 줄이면서 점수는 대체로 유지했습니다. 전문가 궤적으로 지도학습(SFT)한 방식보다도 도구 호출이 18~28% 적었습니다. 소형 모델 에이전트의 지연 시간과 API 비용을 줄이는 실용적인 방향입니다. [arXiv 2611.22539](https://arxiv.org/abs/2611.22539)

### 되돌릴 수 있는가: MCP 도구 536개를 '가역성 등급'으로 분류해 공격 29건 모두 차단

'Can You Undo It?' 논문은 20개 MCP 서버의 도구 536개를 행동의 되돌림 가능성에 따라 등급화하고, 이를 바탕으로 세션 가드를 설계했습니다. 기록된 2,158회 실행에서 가드는 추적 가능한 공격 실행 29건을 모두 막았고, 단순 읽기/쓰기 구분 프록시는 18건만 막았습니다. 정상 실행 1,209회에서 추가된 사람 승인 지점은 9곳에 그쳤습니다. 모든 행동에 승인을 요구하지 않고도 되돌릴 수 없는 행동만 골라 통제할 수 있다는 근거입니다. [arXiv 2611.22075](https://arxiv.org/abs/2611.22075)

### Readie: 에이전트용 코드 샌드박스 시작 지연 3~22배 단축

'Readie'는 AI 에이전트가 코드를 실행할 때 쓰는 샌드박스의 시작 지연을 줄이는 시스템입니다. 공개 스크립트와 LLM이 합성한 스크립트 1만 5,000개를 바탕으로 실행 환경 구성을 계획하는 방식으로, 같은 저장 공간 예산에서 기존 방식보다 시작 지연을 3~22배, 전체 실행 시간을 1.3~3.3배 줄였습니다. 코드를 수십~수백 번 실행하는 에이전트 작업에서 샌드박스 준비 시간이 병목이라는 점을 겨냥했습니다. [arXiv 2611.22171](https://arxiv.org/abs/2611.22171)
