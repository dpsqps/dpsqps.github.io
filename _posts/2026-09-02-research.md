## 모델을 키우지 않고 성능을 올리는 두 가지 방법: 스킬 증류와 개념 해석

9월 2일 공개된 두 편의 연구는 공통적으로 "모델 파라미터를 건드리지 않고" 문제를 풀었습니다. 하나는 깃허브 저장소를 재사용 가능한 스킬로 증류해 에이전트 성능을 끌어올렸고, 다른 하나는 자율주행 신경망의 내부 표현을 사람이 읽을 수 있는 개념으로 감싸 성능 손실 없이 설명 가능성을 확보했습니다.

### Repo-To-Skill — 깃허브 저장소 1,000개를 5,000개 스킬로 증류

9월 2일 arXiv에 공개된 'Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills'(arXiv:2609.02749)는 깃허브 저장소에 암묵적으로 담긴 운영 지식을 자동 추출해 재사용 가능한 스킬로 패키징하는 DisCo 기법을 제안합니다. 연구진은 널리 쓰이는 머신러닝 저장소 1,000개에 DisCo를 적용해 20개 역량 영역, 178개 역량 패밀리로 정리된 5,000개 이상의 검증된 스킬로 구성된 AREX-Skill 라이브러리를 만들었습니다. 증류는 두 가지 형태로 작동합니다. 널리 쓰이는 저장소를 범용 스킬로 압축하는 태스크 비의존 방식과, 특정 과제가 요구하는 스킬만 뽑아내는 태스크 지향 방식입니다. 백본을 GPT-5.5로, 연구 하네스와 실행 예산을 고정한 조건에서 스킬을 장착한 연구 에이전트는 MLE-bench 134.3%, PaperBench 34.4%, FrontierCS 9.2%, PassNet 14.0%의 상대 성능 향상을 기록했습니다. 모델을 재학습하지 않고 컨텍스트에 무엇을 넣느냐만 바꿔 얻은 수치라는 점이 핵심입니다. [arXiv:2609.02749](https://arxiv.org/abs/2609.02749) / [AREX-Skill 저장소](https://github.com/VectorSpaceLab/AREX-Skill)

### CW-Net — 자율주행 판단을 실시간으로 말로 설명하다

모셔널(Motional)과 MIT 연구진이 자율주행차의 주행 판단을 실시간으로 설명하는 Concept-Wrapper Network(CW-Net)를 네이처에 발표했습니다. CW-Net은 자율주행 시스템 내부 신경망의 논리를 '정지 차량에 접근 중', '자전거와 근접' 같은 사람이 이해할 수 있는 개념으로 변환해, 사후 재구성이 아니라 판단이 일어나는 순간에 대시보드에 표시합니다. 벤치마크 결과 기존 최상위 자율주행 알고리즘과의 성능 차이는 1% 미만이었습니다. 실제 라스베이거스 도로에서 운행한 결과 두 가지 실질적 결함이 드러났습니다. 학습 데이터의 환각된 정지 차량 때문에 트래픽 콘 근처에서 반복적으로 정차하던 문제, 그리고 감지된 자전거 이용자가 실제 제동 근거가 아니었고 별도 백업 안전 시스템이 제동을 수행하고 있었다는 사실입니다. 모셔널의 로라 메이저 CEO는 엔드투엔드 방식만으로는 "80~90%, 잘해야 95% 수준의 해법"에 도달할 뿐 운전자 제거나 도시·커뮤니티의 신뢰 획득에는 부족하다고 지적했습니다.
