## 플래그십 성능을 5분의 1 가격에 — 오픈AI가 DevDay에서 꺼낸 'GPT-6.1 Sol'

하루 전 GPT-6.1 Astra 출시를 취소했던 오픈AI는 9월 29일(현지시간) DevDay 2026에서 방향을 바꿔 '싸고 빠른' 중급 모델을 내놨습니다. 오늘 모델 소식은 이 한 건이 전부지만, 가격 대비 성능 곡선을 다시 그리는 발표입니다.

### 오픈AI 'GPT-6.1 Sol' 출시 — 입력 100만 토큰당 2달러, DeepSWE에서 Astra와 동급

오픈AI는 9월 29일 GPT-6 Sol 출시 일주일 만에 후속작 GPT-6.1 Sol을 공개했습니다. API 가격은 입력 100만 토큰당 2달러, 캐시 입력 0.10달러, 출력 10달러이며, 27만 2,000 토큰을 넘는 프롬프트는 입력·캐시 단가 2배, 출력 단가 1.5배가 적용됩니다. 컨텍스트는 입력 105만 토큰, 최대 출력 12만 8,000 토큰입니다. 에이전틱 코딩 벤치마크 DeepSWE v1.1에서 플래그십 GPT-6 Astra와 같은 정확도를 약 5분의 1 비용으로 냈고, AutomationBench에서는 앤트로픽 Claude Opus 5.5보다 2.2%p 높았습니다. 다만 보안(ExploitBench Internal Port 21.5% 대 Astra 31.5%)과 생물학(TroubleshootingBench 47.96% 대 63.46%) 영역에서는 격차가 뚜렷해, 오픈AI가 위험 역량을 의도적으로 낮춘 '중급 모델'로 포지셔닝한 것으로 보입니다. `none`·`minimal` 추론 강도를 지원하지 않고 Chat Completions에서는 도구 호출이 불가해 Responses API로 이전해야 한다는 점도 개발자에게는 실질적인 변화입니다. API, ChatGPT Work, Codex, GitHub Copilot Pro+ 등에서 바로 쓸 수 있습니다.
