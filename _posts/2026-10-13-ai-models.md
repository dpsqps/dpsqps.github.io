## 프런티어에 올라선 메타, 프런티어를 잠그는 앤트로픽

10월 12일 하루에 두 가지 방향의 발표가 겹쳤다. 메타는 처음으로 "프런티어급"이라 부르는 모델을 내놓으면서 상위 버전을 API에서 뺐고, 앤트로픽은 자사 모델의 추론 과정을 경쟁사가 베껴 가지 못하게 막은 결과를 수치로 공개했다. 둘 다 "가장 좋은 출력을 누구에게까지 내줄 것인가"라는 같은 질문에 대한 답이다.

### 메타 Muse Wonder·Wonder Full: 입력 4달러·출력 20달러, 상위 모델은 구독 전용

메타 초지능 랩(MSL)이 10월 12일 Muse Wonder와 Muse Wonder Full을 공개했다. 메타는 블로그에서 두 모델을 "스케일링 사다리의 다음 단계"라고 표현했고, 테크크런치는 이를 메타의 첫 프런티어 모델로 소개했다. 두 모델은 오하이오주 프로메테우스 데이터센터에서 학습됐으며 가중치는 공개되지 않는다.

가격과 접근 범위가 핵심이다. Muse Wonder는 메타 모델 API에서 입력 100만 토큰당 4달러, 출력 100만 토큰당 20달러, 캐시 입력 0.20달러에 제공되고 컨텍스트 창은 약 100만 토큰이다. 반면 상위 모델인 Wonder Full은 종량제 API로는 쓸 수 없고 Muse Code 구독(월 50달러 'Power Usage', 월 200달러 'Maximum Usage')으로만 제공된다. 벤처비트는 Muse Code 구독의 기본값이 프롬프트·코드·출력을 향후 모델 개선에 쓸 수 있는 '컨트리뷰터 모드'라는 점도 짚었다.

성능 수치는 메타가 제시한 표 기준이다. 장시간 코딩 벤치마크 SWE-Marathon에서 Wonder Full 57.5, Wonder 53.1로 GPT-6 Astra(42.5)와 Claude Opus 5.5(46.3)를 앞섰고, DeepSWE 1.1에서도 79.0을 기록했다. 다만 Terminal-Bench 4.0에서는 Wonder Full 57.1로 Opus 5.5(59.6)와 Astra(59.1)에 뒤졌고 HealthBench Pro도 62.3 대 65.6으로 밀렸다. 벤처비트는 이 표가 제3자 평가와 메타 자체 평가를 섞었고 일부 코딩 비교는 사용 도구가 달라 완전히 통제된 비교가 아니라고 지적했다. Artificial Analysis 지능 지수에서는 Wonder Full 56, Wonder 52로 Opus 5.5(58)보다 낮다. 메타가 따로 강조한 차별점은 대화 간 맥락을 유지·종합하는 '액티브 메모리'다. [TechCrunch](https://techcrunch.com/2026/10/12/meta-releases-its-first-frontier-model-muse-wonder/) / [VentureBeat](https://venturebeat.com/technology/metas-new-muse-wonder-and-muse-wonder-full-models-achieve-frontier-performance-but-only-the-weaker-one-is-available-via-api)

### 앤트로픽, 증류 방어 결과 공개: 탈취 데이터 90~99% 감소, 오탐률 0.1% 미만

앤트로픽은 10월 12일 연구 글에서 경쟁사가 Claude의 출력을 대량 수집해 자사 모델을 학습시키는 '증류 공격'에 대한 방어 결과를 공개했다. 초기 증거 기준으로 증류 시도자가 수집한 데이터량이 약 90~99% 줄었고, 플랫폼에서 추출된 추론 토큰 수는 이전의 10~100분의 1 이하라고 밝혔다.

방어는 세 겹이다. 첫째, 추론 내용이 대화·모델·계정 사이로 옮겨지지 않도록 막았다(2026년 8월 31일 이후 생성된 API 계정은 Claude의 이전 컨텍스트를 편집할 수 없다). 둘째, 추출 요청을 걸러내는 2단계 분류기를 배치했는데 오탐률은 0.1% 미만이라고 한다. 셋째, 반복 시도 계정에 사용 한도 강화와 계정 정지를 적용해 수만 개 계정을 정지했고, 캠페인 시작 후 2시간 안에 차단되는 경우가 많다고 밝혔다. 추론을 보호해야 하는 이유도 수치로 제시했다. Claude Opus 4.8의 전체 추론 기록으로 학습한 모델은 SWE-bench Verified 80.4%였지만 요약된 기록으로 학습하면 71.8%에 그쳤다.

앤트로픽은 한계도 명시했다. 증류는 "쫓고 쫓기는 게임"이라 효과가 얼마나 지속될지 모르고, 아직 고도로 정교하고 끈질긴 우회 시도는 겪지 않았다고 적었다. 또한 9월 24일부터 응답 전 세이프가드에 차단된 요청에도 과금하고 있어, 0.1% 미만의 오탐에 걸린 정상 요청도 비용을 낸다는 점을 트레이드오프로 인정했다. 로이터는 앤트로픽이 중국 즈푸(Z.ai)를 GLM-5.3 개발 과정에서 Claude 증류를 시도한 회사로 지목했으며 Z.ai는 논평 요청에 즉시 응답하지 않았다고 전했다.
