## 같은 날 나온 두 갈래의 신모델: OpenAI는 성능, 마이크로소프트는 가격

11월 17일(현지시간) OpenAI가 GPT-6.2 두 종을 내놓았고, 같은 날 마이크로소프트는 Ignite 2026에서 자체 MAI 모델 7종을 공개했습니다. OpenAI는 최상위 성능 경쟁에, 마이크로소프트는 "경쟁 모델 대비 몇 % 가격"이라는 가성비 경쟁에 초점을 맞췄습니다.

### OpenAI 'GPT-6.2 Astra'·'Sol' 출시: Astra 입력 100만 토큰당 8달러

OpenAI는 11월 17일 GPT-6.2 Astra와 GPT-6.2 Sol을 공개했습니다. Sol은 일상 업무용 기본 모델, Astra는 전문 업무에서 가장 높은 품질을 내도록 맞춘 상위 모델입니다. 9to5Google에 따르면 100만 토큰당 가격은 Astra가 입력 8달러·캐시 입력 0.40달러·출력 40달러, Sol이 입력 2달러·캐시 입력 0.10달러·출력 10달러이며, Sol 가격은 전작과 같습니다. 두 모델은 ChatGPT Work와 Codex에서 Plus·Pro·Enterprise·Edu 사용자 전원에게 제공됩니다. 9to5Google은 이번 출시를 경쟁사 신모델이 나온 지 약 1주일 만에 성능 선두를 되찾으려는 대응으로 해석했습니다. 다만 기사에는 구체적인 벤치마크 수치나 컨텍스트 길이가 나와 있지 않습니다. [9to5Google](https://9to5google.com/2026/11/17/openai-releases-gpt-6-2-astra-and-sol-for-complex-projects-a-week-after-claude-5-2)

### 마이크로소프트 MAI 모델 7종 공개: 'MAI Code 2'는 경쟁 모델 품질 98%를 가격 약 40%에

마이크로소프트 AI(MAI)는 11월 17일 Ignite에 맞춰 MAI Cyber 2 Flash, MAI Code 2, MAI Code 2 Flash, MAI Image 2.7, MAI Realtime 1, Dragon Copilot Transcribe, Decision 1.1 등 7종을 공개했습니다. 회사 발표에 따르면 MAI Code 2는 DeepSWE 1.1·Terminal Bench 2.1 등 4개 벤치마크 평균에서 GPT-6.1 Sol 코딩 품질의 98%를 약 40% 가격에 내며, 블라인드 프런트엔드 평가에서 개발자의 64%가 GPT-6 Sol보다 MAI Code 2를 선호했습니다. 음성 모델 MAI Realtime 1은 오디오 1분당 0.01달러부터 시작합니다. 의사결정 모델 Decision 1.1은 "GPT-Sol 6.1 대비 50배 빠르고 79배 저렴하다"고 회사는 주장합니다. MAI Code 2는 GitHub Copilot에서 바로 쓸 수 있고, 이미지 모델은 Microsoft Foundry로 제공됩니다. 모든 수치는 마이크로소프트 자체 발표이며 외부 검증은 아직 없습니다. [Microsoft AI](https://microsoft.ai/news/microsoft-ignite-2026)
