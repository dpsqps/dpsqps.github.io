## 모델을 갈아탄 뒤에 남는 것들: 메모리, 궤적, 그리고 암기

9월 7일 arXiv에 공개된 논문들은 공교롭게도 같은 질문을 다른 각도에서 던집니다. **모델이 바뀌어도 살아남는 자산은 무엇인가.** 에이전트의 기억, 학습 궤적, 그리고 벤치마크 점수의 신뢰성이 각각 도마에 올랐습니다.

### 에이전트의 기억은 모델 교체를 견디는가 — 지식그래프 ±0.0020 vs 요약노트 최대 13%p 붕괴

앙키트 고얄과 자이딥 레이는 논문 **"Does Your Agent's Memory Survive a Model Upgrade?"**(arXiv:2609.05339, 9월 4일 제출·9월 7일 공개)에서 모델을 교체했을 때 에이전트 메모리가 얼마나 이식되는지를 통제 실험으로 측정했습니다. **48개 합성 히스토리**를 대상으로 네 가지 저장 방식 — 원문 장문맥 읽기(LC-RAW), 청크 기반 RAG, 모델이 압축한 자연어 노트(NOTES), 정규화된 고정 스키마 지식그래프(KG-fixed) — 을 비교했습니다.

결과는 극명합니다. **고정 스키마 지식그래프는 모델 교체 후 정확도 변화가 ±0.0020에 그친** 반면, **모델이 압축한 노트는 이전 방향에 따라 +9.91%p에서 -13.28%p까지 흔들렸습니다.** 즉 노트 방식은 그것을 만든 모델에 강하게 종속돼 있었습니다. 임베딩 측면에서도 혼합 인덱스는 4.96점 개선에 그친 반면 **전면 재임베딩은 11.90점** 개선을 가져와, 임베딩 공간을 섞지 말아야 함을 시사했습니다.

원인 분석은 더 실용적입니다. 노트 기반 성능 저하의 **80%는 최초 생성 시점의 정보 손실**에서, RAG 시스템 결손의 **81%는 검색 실패**에서 비롯됐습니다. 저장소만 손보는 복구는 **48개 사례 전부에서 목표치 회복에 실패**한 반면, 원본 히스토리를 보존한 경우 **48건 중 34건에서 복구에 성공**했습니다. 결론은 명확합니다. 원문을 버리지 말 것. [arXiv:2609.05339](https://arxiv.org/abs/2609.05339)

### CUA-Universe — GUI에 CLI를 더하자 9B 모델이 39.3점 오르고 토큰은 60% 줄었다

연구진은 **"CUA-Universe: A Scalable and Dynamic Environment for Hybrid GUI+CLI Agents"**(arXiv:2609.05374)에서 컴퓨터 사용 에이전트가 화면 클릭에만 의존해 비효율적으로 움직인다는 문제를 다뤘습니다. 해법은 GUI와 명령줄(CLI)을 함께 쓰게 하는 것입니다.

파이프라인은 세 부분입니다. **App-Forge**는 **16개 실제 애플리케이션**을 CLI가 붙은 재현 가능한 가상머신으로 변환하고, **Task-Weave**는 난이도를 조절할 수 있는 혼합 과제를 생성하며, **Path-Steer**는 효율적인 경로를 따라 롤아웃을 최적화해 검증된 궤적을 수집합니다.

이 데이터로 학습한 **90억(9B) 파라미터 모델**의 성능 향상 폭이 눈에 띕니다. 자체 평가셋 CUA-Verse에서 **+39.3점, 단계 수 -37%, 토큰 -60%**, 공개 벤치마크 OSWorld에서 **+16.8점, 단계 -57%, 토큰 -44%**, OSWorld-MCP에서 **+7.84점, 단계 -27%, 토큰 -30%** 를 기록했습니다. 점수와 비용이 동시에 개선됐다는 점에서, 단일 모달리티 학습보다 GUI+CLI 혼합 학습이 유리하다는 근거가 됩니다. [arXiv:2609.05374](https://arxiv.org/abs/2609.05374)

### KOPA-Bench — 한국 공공 API 145개 과제로 잰 오픈소스 모델의 다단계 도구 호출

연구진(Dain Kim 외 4인)은 **"Multi-Step Tool-Calling over Korean Open Public APIs"**(arXiv:2609.05395)에서 데이터 주권 규제 탓에 오픈소스 모델을 써야 하는 공공기관의 현실적 제약을 출발점으로 삼았습니다. 문제는 오픈소스 모델이 다단계 도구 호출에서 크게 뒤처지는데, 그 격차를 정량화한 벤치마크가 없었다는 점입니다.

연구진은 실제 정부 API를 대상으로 한 **145개 과제로 구성된 KOPA-Bench**를 공개하고, 데이터 합성 기법 **EDGE**를 함께 제시했습니다. EDGE는 한 도구의 출력이 다음 도구의 입력이 될 수 있는 관계를 그래프로 구성하고, 그 연결을 **실제 라이브 API 실행으로 검증**한 뒤 실행 가능한 다단계 시퀀스를 생성합니다. 합성 데이터로 **GRPO 미세조정한 9B 모델이 같은 계열의 미조정 27B 모델에 근접하는 성능**을 냈고, KOPA-Bench와 공개 벤치마크 BFCL 양쪽에서 개선이 확인됐습니다. 이 논문은 **EMNLP 2026 산업 트랙**에 채택됐습니다. [arXiv:2609.05395](https://arxiv.org/abs/2609.05395)

### '분자 기시감' — 22개 프런티어 모델의 예측은 얼마나 암기였나

연구진은 **"Molecular Déjà Vu: Digit-Level Retrieval of Published Values in Frontier Language Models"**(arXiv:2609.05381)에서 언어모델이 분자 물성을 정말 '예측'하는지, 아니면 학습 데이터의 값을 **자릿수 단위로 그대로 꺼내오는지** 검증했습니다.

**22개 프런티어 모델을 12개 회귀 벤치마크**에 걸쳐 시험한 결과, 원문 그대로의 값 인출은 널리 나타나되 벤치마크별 편차가 컸습니다. **5개 데이터셋에서는 절반이 넘는 모델이 이 행태를 보였습니다.** 추론 수준을 높이면 인출로 판정되는 사례가 **89% 더 자주** 포착됐고, 강한 모델은 인출을 억제해도 **변형된 SMILES 문자열과 원 레이블을 알아보는** 경우가 있었습니다. 다만 인출을 억제했을 때 모델 간 예측 오차가 서로 가까워졌다는 점에서, 암기 밖의 일반적 예측 능력 자체는 존재한다는 해석도 함께 제시됐습니다. 시사점은 벤치마크 해석에 있습니다. **모델 순위표의 일부는 능력 차이가 아니라 '무엇을 더 많이 외웠는가'의 차이일 수 있다는 것입니다.** [arXiv:2609.05381](https://arxiv.org/abs/2609.05381)
