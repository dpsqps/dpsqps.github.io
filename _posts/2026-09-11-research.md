## 평가 예산, 게이팅 계수, 그리고 '거꾸로 추론하기'

9월 10일 arXiv에 올라온 세 편은 모두 **"어떻게 고를 것인가"**를 다룬다. 어떤 스킬을 평가에 태울지, 어떤 손실에 가중치를 줄지, 여러 에이전트가 엇갈릴 때 누구를 믿을지 — 셋 다 모델을 키우지 않고 선택 규칙만 바꿔 점수를 움직였다.

### COBRA-Skills: 에이전트 스킬 최적화 비용을 55~58% 깎은 밴딧 예산 배분

LLM 에이전트는 과거 경험에서 뽑아낸 재사용 가능한 '스킬'로 이득을 보지만, 기존 스킬 최적화 기법은 실제 실행 기반 평가에 의존해 비용이 크고 과제 데이터도 많이 요구한다. COBRA-Skills(arXiv:2609.11682)는 이를 **동적으로 변하는 후보 공간 위의 예산 제약 순차 최적화** 문제로 다시 정의했다. 컨텍스추얼 밴딧으로 유망하거나 정보량이 큰 후보에만 평가 예산을 몰아주고, 실행 피드백으로 스킬 집단을 계속 진화시킨다.

결과는 비용 쪽에서 나왔다. 기존 SkillOpt 대비 최적화 비용을 **55~58% 절감**했고, 벤치마크당 고유 최적화 예제는 **50개**만 썼다. 6개의 이질적 에이전트 벤치마크와 3개 타깃 모델에서 비교 기법 중 가장 높은 평균 성능을 유지했다. 저자들은 **에이전트 하네스가 바뀌어도 견고**했고, 타깃 모델이 스스로 스킬을 생성·수정하는 설정에서도 작동했다고 보고한다. 스킬 라이브러리의 진짜 비용이 '저장'이 아니라 '검증'이라는 점을 정면으로 공략한 셈이다. [arXiv:2609.11682](https://arxiv.org/abs/2609.11682)

### 온폴리시 증류의 게이팅을 4개 계수로 일반화 — 36칸 중 33칸에서 기존 기법을 앞섰다

온폴리시 지식 증류(OPD)에서 토큰별로 순방향/역방향 KL 손실에 가중치를 주는 게이팅은 이미 표준 기법이 됐지만, EOPD(2026)와 ToDi(2025) 같은 기존 방법은 **게이팅 신호 하나와 방향 하나를 고정**해 놓았고 둘을 직접 비교한 연구도 없었다. 이 논문(arXiv:2609.11768)은 게이트를 `λ_t = σ(a·h_t + b·u(x) + c + d·gap_t)`라는 **4계수 파라미터화**로 확장했다. EOPD와 ToDi의 방향 정렬 근사가 이 식의 1차원 제약 사례로 각각 등장하고, 여기에 다채널 결합과 명시적 바이어스가 자유도로 추가된다.

검증은 TweetEval의 감정·혐오 과제, 교사 **Qwen3-32B** → 학생 **Qwen3-4B** 설정에서 이뤄졌다. 전체 계수군의 설정들은 크기를 맞춘 단일 채널(엔트로피만 / 갭만) 1차원 제약 대비 **비교 가능한 36칸 중 33칸에서 더 높은 정확도**를 기록했다. 효과적 KL을 맞춘 정적 베이스라인과의 26칸 분리 실험에서는 동적 게이팅이 **19칸**에서 앞섰다. 다만 저자들은 헤드라인 비교 9건의 3-시드 재현에서 방향성은 일관됐지만 개별 효과는 더 작고 n=3에서는 통계적 유의성에 이르지 못했다고 명시했다 — 결론을 과장하지 않은 드문 서술이다. [arXiv:2609.11768](https://arxiv.org/abs/2609.11768)

### When Agents Disagree: 역방향 사후분포를 라벨 없는 기준점으로 쓰다

멀티 LLM 에이전트의 집단 의사결정은 보통 투표나 LLM 심판 같은 **순방향 추론**으로 충돌을 정리한다. 이 논문(arXiv:2609.11709)은 방향을 뒤집었다. 명시적 우도 모델에서 **역방향 사후분포**를 구성하고, 순방향 사후분포와의 옌센-섀넌 발산으로 각 에이전트의 '경로 간 일관성(cross-path consistency)'을 매겨 순위를 만든다. 라벨이 필요 없는 기준점이라는 게 핵심이다.

세 가지 전략을 제시한다 — MinJS(하드 선택), FwdJS(소프트 재가중), LogLin(로그선형 융합). **DDXPlus** 벤치마크에서 **5개 LLM 백본** 전반에 걸쳐 일관된 개선이 나왔고, MinJS는 모든 백본에서 무작위 선택을 앞섰으며 LogLin이 전체 최고 성능을 기록했다. 가장 큰 이득은 **에이전트들이 실제로 엇갈리는 부분집합**에서 나왔다. 흥미로운 관찰은 역방향 사후분포 자체의 단독 정확도가 더 낮아도 결정 기준점으로는 순방향 전용 대안보다 유용했다는 점이다. 앞의 두 논문과 함께 놓으면 방향은 같다: 더 큰 모델이 아니라 더 나은 선택 규칙. [arXiv:2609.11709](https://arxiv.org/abs/2609.11709)
