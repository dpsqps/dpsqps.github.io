## 에이전트가 '도구'에서 '동료'로 — 협업 워크스페이스 경쟁이 열렸다

이번 주 엔터프라이즈 AI 도구의 흐름은 분명하다. 프롬프트에 답하는 챗봇을 넘어, 사람과 나란히 업무 공간에 상주하며 스스로 작업을 수행하는 '에이전트 워크스페이스'가 잇따라 공개됐다. HubSpot과 블록(Block)이 각기 다른 접근으로 같은 목표를 겨냥했다.

### HubSpot, 'Agent Hub·Agent Builder' 퍼블릭 베타 출시

HubSpot이 7월 23일 고투마켓(GTM) 팀을 겨냥한 AI 에이전트 관리 도구 **Agent Hub**와 **Agent Builder**를 프로페셔널·엔터프라이즈 등급 대상 퍼블릭 베타로 공개했다. Agent Hub는 흩어져 있던 개별 에이전트를 한 화면에 모아 실시간 상태와 최근 성과를 '수요 창출·거래 성사·고객 관리' 같은 목표 단위로 보여준다. Agent Builder는 Smart CRM에 이미 쌓인 고객 컨텍스트를 활용해 자연어로 맞춤형 에이전트를 조립하는 노코드 캔버스다. 베타 기간 중 Agent Hub는 두 등급에 기본 포함되며, Agent Builder로 만든 에이전트가 실제 작업을 수행할 때만 HubSpot 크레딧이 차감된다. HubSpot은 사례로 교육기업 Ignite Reading이 25개 주에 걸친 업무에서 연간 **350시간**을 절감했다고 밝혔다. 핵심은 '컨텍스트 공유'다. 영업 에이전트가 접촉하려는 고객이 마침 상담 에이전트가 처리 중인 미해결 불만 계정일 때, 두 에이전트가 서로를 인지하지 못하는 파편화 문제를 정면으로 겨냥했다. [HubSpot](https://www.hubspot.com/company-news/meet-agent-hub-and-agent-builder) / [CMSWire](https://www.cmswire.com/customer-experience/hubspot-debuts-agent-hub-to-unify-ai-agents/)

### 블록(Block), 오픈소스 협업공간 'Buzz' 공개 — 에이전트가 서명한다

핀테크 기업 블록이 7월 21일 Apache 2.0 라이선스의 오픈소스 협업 워크스페이스 **Buzz**를 내놨다. 팀 채팅·Git 호스팅·AI 에이전트 조율을 탈중앙 프로토콜 Nostr 위에 결합한 것이 특징이다. 여기서 AI 에이전트는 단순 챗봇이 아니라 자체 암호화 키페어를 가진 정식 구성원으로, 사람 소유자와 2차 서명으로 연결돼 메시지 작성·코드 리뷰·자동화 실행에 참여한다. 현재 버전은 **0.4.21**로 macOS·윈도·리눅스 데스크톱 클라이언트를 제공하며, 모바일 앱은 개발 중이다. 아키텍처는 모델에 종속되지 않아 Claude Code, OpenAI Codex, Goose 등 여러 LLM을 지원한다. 무엇보다 블록은 사내에서 Buzz를 슬랙·깃허브 대체재로 실제 운영하며 '자기 요리 먹기(dogfooding)'를 실천하고 있다는 점에서, 탈중앙 신원 스택의 실전 검증 사례로 주목된다. [SiliconANGLE](https://siliconangle.com/2026/07/21/block-launches-buzz-open-source-workspace-humans-ai-agents/) / [TechTimes](https://www.techtimes.com/articles/321242/20260722/block-launches-buzz-open-source-workspace-where-ai-agents-sign-their-own-work.htm)
